اكتب بالعربي،
وخلّي الكمبيوتر يفهمك

APL لغة برمجة عربية مبنية على Python. الكود بيتكتب بالعربي، وبيتحوّل لـ Python نظيف ويشتغل. من غير تثبيت حاجة.

⬇ نزّل APL جرّب في المتصفح 


  


  

    
ليه APL؟
لغة كاملة، بس بلسانك.

    

      
✍️
كود عربي حقيقي
شروط وحلقات ودوال وأصناف، وحتى أسماء دوال النصوص والقوائم بالعربي.

      
🐍
فوق Python
بيتحوّل لـ Python نظيف، فتستفيد من سرعته ومكتبته القياسية.

      
📦
مكتبات معرّبة
ثبّت مكتبة بأمر واحد، وهتجيب معاها اعتمادياتها تلقائيًا.

      
🧪
ملعب في المتصفح
جرّب الكود فورًا من غير ما تحمّل أي حاجة.

      
🖥️
ويندوز ولينكس وماك
ملف تنفيذي واحد جاهز، لا يحتاج Python. (ماك: تجريبي وغير موقّع.)

      
🛡️
أخطاء مفهومة
رسائل الأخطاء بالعربي ومعاها رقم السطر.

    

  


  

    
نزّل APL Alpha
اختار نظامك. دي نسخة Alpha، أكيد فيها أخطاء.

    

      
🪟
ويندوز
مثبّت بيضيف APL للـ PATH وبيعمل أيقونات للبرامج في قائمة ابدأ. ويندوز 10 وما فوق. غير موقّع، فممكن SmartScreen يحذّرك.
نزّل لويندوز

      
🐧
لينكس
حزمة deb: sudo apt install ./الملف.deb. بتضيف الأمر apl وأيقونات البرامج. Ubuntu 22.04 أو أحدث.
نزّل للينكس

      
🍎
ماك
مثبّت pkg بيضيف apl للـ PATH وبيحط البرامج في Applications. غير موقّع، واتجرب في CI بس ومحدش جربه بإيده. ممكن ماك يحذّرك.
Apple Silicon (M1 وأحدث)

Intel
