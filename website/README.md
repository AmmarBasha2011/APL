# موقع APL

موقع ثابت بالعربي (RTL) من خمس صفحات: الرئيسية، مرجع اللغة، المميزات، الأمثلة، المكتبات. بدون أي موارد خارجية.

```bash
python website/build.py          # يبني الصفحات من docs/ و examples/ و README
python website/build.py --check  # يتأكد أن الصفحات المبنية محدّثة
```

للمعاينة محليا: افتح `website/index.html` في المتصفح، أو `python -m http.server -d website`.

الصفحات تُبنى من ملفات المشروع نفسها (مرجع اللغة، المميزات، جدول المكتبات، الأمثلة)، فأعد البناء بعد أي تغيير فيها. لا يوجد نشر تلقائي.
