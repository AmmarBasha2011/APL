ابدأ في دقيقة

تحتاج Python 3.14 أو أحدث. لا شيء آخر.

  1. حمّل المشروع:

    git clone https://github.com/AmmarBasha2011/APL.git
cd APL

  2. شغّل مثالا جاهزا:

    python apl.py examples/01-calculator.apl

  3. أو جرّب الكود مباشرة:

    python apl.py -c "اطبع 'مرحباً'"
python apl.py repl

ثم اقرأ مرجع اللغة وتصفّح الأمثلة.
