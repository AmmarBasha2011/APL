# APL - لغة عمار البرمجية · إضافة VS Code

تلوين الصياغة واقتراحات الأكواد لملفات `.apl`.

## التثبيت

1. نزّل المجلد `editors/vscode` من الريبو.
2. في VS Code: `Ctrl+Shift+P` ← `Extensions: Install from VSIX...` بعد التغليف،
   أو للتجربة السريعة انسخ المجلد إلى:
   - ويندوز: `%USERPROFILE%\.vscode\extensions\apl-ammar`
   - لينكس/ماك: `~/.vscode/extensions/apl-ammar`
3. أعد تشغيل VS Code وافتح أي ملف `.apl`.

## اللي بتعمله

- تلوين الكلمات المفتاحية: `لو`، `والا`، `لكل`، `طالما`، `دالة`، `صنف`، `حاول`، `امسك`، `أخيراً`.
- تلوين الثوابت: `صواب`، `خطأ`، `لا_شيء`.
- تلوين الدوال الجاهزة: `اطبع`، `نطاق`، `طول`، `اقرأ`، `اكتب`، `ادخل`.
- تلوين دوال النصوص والقوائم بعد النقطة: `.علوي`، `.تقسيم`، `.أضف`.
- النصوص المنسّقة: الجزء اللي بين `{}` بيتلوّن لوحده.
- اقتراحات جاهزة (snippets) لأصناف، دوال، حلقات، ومعالجة أخطاء.

الترخيص: PSF-2.0، نفس ترخيص APL وPython.
