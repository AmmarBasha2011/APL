# مكتبة المعرفات الفريدة — `uuid`

توليد المعرفات الفريدة (UUID) بنسخها المختلفة.

**13 عنصراً عربياً** (الدوال: 7، الخصائص: 2، الثوابت: 4).

## الدوال (7)

| العربي | Python |
|--------|--------|
| `معرف_فريد` | `uuid.uuid4` |
| `معرف_نص` | `str` |
| `معرف_عشوائي` | `uuid.uuid4` |
| `معرف_زمني` | `uuid.uuid1` |
| `معرف_بالاسم` | `uuid.uuid3` |
| `معرف_من_نص` | `uuid.UUID` |
| `معرف_فارغ` | `uuid.UUID` |

## الخصائص (2) — `UUID_PROPS`

| العربي | Python |
|--------|--------|
| `نسخة_المعرف` | `version` |
| `معرف_النسخة` | `version` |

## الثوابت (4) — `UUID_CONSTANTS`

| العربي | Python |
|--------|--------|
| `نطاق_دنس` | `uuid.NAMESPACE_DNS` |
| `نطاق_رابط` | `uuid.NAMESPACE_URL` |
| `نطاق_معرف` | `uuid.NAMESPACE_OID` |
| `نطاق_شهادة` | `uuid.NAMESPACE_X500` |

## مثال

```apl
المتغير م = معرف_فريد()
اطبع "المعرف:", معرف_نص(م)
اطبع "النسخة:", م.نسخة_المعرف

# معرف ثابت مشتق من نص
المتغير ثابت = معرف_بالاسم(نطاق_دنس, "apl.example.com")
اطبع معرف_نص(ثابت)
```
