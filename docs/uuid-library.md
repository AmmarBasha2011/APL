# مكتبة المعرفات الفريدة — `uuid`

توليد المعرفات الفريدة (UUID) بنسخها المختلفة.

**13 عنصر** (7 دالة، 2 خاصية، 4 ثابت).

## الدوال

| العربي | Python | الوصف |
|--------|--------|-------|
| `معرف_فريد(...)` | `uuid.uuid4` | معرف UUID v4 عشوائي |
| `معرف_نص(...)` | `str` | تحويل معرف إلى نص |
| `معرف_عشوائي(...)` | `uuid.uuid4` | اسم بديل |
| `معرف_زمني(...)` | `uuid.uuid1` | معرف v1 مبني على الوقت |
| `معرف_بالاسم(...)` | `uuid.uuid3` | معرف ثابت v3 (استخدم نطاق_دنس) |
| `معرف_من_نص(...)` | `uuid.UUID` | نص -> UUID |
| `معرف_فارغ(...)` | `uuid.UUID` | معرف فارغ |

## خصائص الكائن (Properties)

تُستخدم بعد النقطة: `كائن.رقم_السنة`

| العربي | Python | الوصف |
|--------|--------|-------|
| `نسخة_المعرف` | `version` | رقم نسخة الـ UUID |
| `معرف_النسخة` | `version` | اسم بديل |

## ثوابت (Constants)

| العربي | Python | الوصف |
|--------|--------|-------|
| `نطاق_دنس` | `uuid.NAMESPACE_DNS` | NAMESPACE_DNS |
| `نطاق_رابط` | `uuid.NAMESPACE_URL` | NAMESPACE_URL |
| `نطاق_معرف` | `uuid.NAMESPACE_OID` | NAMESPACE_OID |
| `نطاق_شهادة` | `uuid.NAMESPACE_X500` | NAMESPACE_X500 |

## أمثلة

```apl
المتغير م = معرف_فريد()
اطبع "المعرف:", معرف_نص(م)
اطبع "النسخة:", م.نسخة_المعرف

# معرف ثابت مشتق من نص
المتغير ثابت = معرف_بالاسم(نطاق_دنس, "apl.example.com")
اطبع معرف_نص(ثابت)
```
