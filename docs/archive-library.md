# مكتبة الأرشيف والضغط — `archive`

أرشيفات ZIP و TAR، وضغط النصوص والملفات بـ `gzip` و `bz2` و `lzma`، كلها بالعربي
وبدون أي مكتبة خارجية — تعتمد على حزمة Python القياسية فقط.

**105 عناصر** (59 دالة، 20 دالة كائن، 12 خاصية، 11 ثابتاً، 4 معاملات) — بعد إزالة التكرار: 105 مفاتيح فريدة.

> **الفكرة:** الأرشيف = ملف واحد داخله أعضاء (ملفات/مجلدات)، ولكل عضو اسم وحجم
> ووقت وتاريخ. في APL تكتب `أنشئ_أرشيف("نسخة.zip", [مجلد])` فتحصل على أرشيف،
> ثم `قائمة_الأرشيف` و`نص_العضو` للقراءة، و`استخرج_الأرشيف` للاستعادة.
> أما الضغط المباشر لنص أو ملف فله ثلاث درجات: `ضغط_نص` (gzip) و`ضغط_قوي` (bz2)
> و`ضغط_فائق` (xz).

---

## 1. إنشاء الأرشيف واستخراجه (ZIP)

| العربي | Python | الوصف |
|--------|--------|-------|
| `أنشئ_أرشيف(ملف, عناصر)` | `zipfile.ZipFile(w)` | إنشاء أرشيف من ملفات أو مجلدات |
| `أنشئ_أرشيف_من_مجلد(ملف, مجلد)` | `ZipFile(w)` + `write` | نفس الدالة (اسم يوضّح النية) |
| `أضف_للأرشيف(ملف, عناصر)` | `ZipFile(a)` | إضافة إلى أرشيف موجود |
| `احذف_من_الأرشيف(ملف, أسماء)` | إعادة بناء | حذف أعضاء (ZIP لا يدعم الحذف أصلاً) |
| `استخرج_الأرشيف(ملف, إلى)` | `extractall` | استخراج آمن ضد الخروج عن المجلد |
| `افتح_أرشيف(ملف, وضع)` | `ZipFile` | كائن أرشيف للعمل عليه سطراً بسطر |
| `أرشيف_جديد(ملف, وضع)` | `ZipFile` | نفس `افتح_أرشيف` (اسم بديل) |
| `أرشيف_للقراءة(ملف)` | `ZipFile(r)` | فتح للقراءة فقط |
| `افتح_أي_أرشيف(ملف)` | ZIP أو TAR | يكتشف النوع ويفتحه تلقائياً |

```apl
# تجهيز مجلد صغير للتجربة
انشئ_مجلدات("المشروع/src", موجود_سلفا = صواب)
اكتب("المشروع/README.md", "# مشروع تجريبي\n")
اكتب("المشروع/src/main.py", "print('مرحباً')\n")

# إنشاء أرشيف من مجلد كامل (يمشي على الشجرة كلها)
أنشئ_أرشيف("نسخة.zip", ["المشروع"])

# استخراج كامل، ثم استخراج عضو واحد فقط
استخرج_الأرشيف("نسخة.zip", "مستخرج")
استخرج_الأرشيف("نسخة.zip", "مستخرج2", أعضاء = ["المشروع/README.md"])
```

> **الأمان:** كل دوال الاستخراج ترفض أي عضو يحتوي `..` أو مساراً مطلقاً
> (`/etc/passwd` أو `C:\...`) قبل فكّ أي بايت — وهي أشهر ثغرة في أدوات الأرشيف
> (zip-slip). ترى رسالة عربية واضحة بدل كتابة ملفات خارج مجلدك.

## 2. السرد والفحص (Inspect)

| العربي | Python | الوصف |
|--------|--------|-------|
| `قائمة_الأرشيف(ملف)` | `namelist` | أسماء الأعضاء |
| `أسماء_الأرشيف(ملف)` | `namelist` | نفس الدالة (اسم بديل) |
| `عدد_الأعضاء(ملف)` | `len(namelist)` | عدد الأعضاء |
| `داخل_الأرشيف(ملف, اسم)` | `name in namelist` | هل العضو موجود؟ |
| `افحص_أرشيف(ملف)` | `is_zipfile` | هل هو ZIP صالح؟ |
| `نوع_الأرشيف(ملف)` | — | `ZIP` / `TAR` / `GZIP` / `BZ2` / `XZ` |
| `بيانات_عضو(ملف, اسم)` | `getinfo` | كائن `ZipInfo` للعضو |
| `معلومات_عضو(ملف, اسم)` | `getinfo` | نفس الدالة (اسم بديل) |
| `حجم_الأرشيف(ملف)` | `os.path.getsize` | حجم الملف على القرص |
| `حجم_غير_مضغوط(ملف)` | `sum(file_size)` | مجموع أحجام الأعضاء قبل الضغط |
| `حجم_بشري(عدد)` | — | `1.4 م.ب` بدل `1468006` |
| `نسبة_الضغط(أصلي, مضغوط)` | — | النسبة المئوية |

```apl
# تجهيز: مجلد وأرشيف صغير للعمل عليهما
لو ليس موجود("المشروع"):
    انشئ_مجلدات("المشروع")
اكتب("المشروع/README.md", "# مشروع تجريبي\n")
أنشئ_أرشيف("نسخة.zip", ["المشروع"])

اطبع "النوع: " + نوع_الأرشيف("نسخة.zip")          # ZIP
اطبع "العدد: " + نص(عدد_الأعضاء("نسخة.zip"))
اطبع "الحجم: " + حجم_بشري(حجم_الأرشيف("نسخة.zip"))
اطبع "هل يوجد README؟ " + نص(داخل_الأرشيف("نسخة.zip", "المشروع/README.md"))
```

## 3. ملخص وإحصاءات

| العربي | النتيجة |
|--------|---------|
| `ملخص_الأرشيف(ملف)` | قائمة أسطر: كل عضو وحجمه قبل/بعد الضغط + سطر الإجمالي |

| `بيانات_الأرشيف(ملف)` | قاموس: `عدد_الأعضاء`, `الحجم_الأصلي`, `الحجم_المضغوط`, `نسبة_الضغط`, `الحجم_المقروء` |

```apl
# تجهيز: مجلد وأرشيف صغير للعمل عليهما
```

## 4. قراءة أعضاء بدون استخراج

| العربي | Python | الوصف |
|--------|--------|-------|
| `نص_العضو(ملف, اسم)` | `read().decode()` | نص العضو مباشرة |
| `اقرأ_من_الأرشيف(ملف, اسم)` | نفس الدالة | اسم بديل |
| `بايتات_العضو(ملف, اسم)` | `read()` | بايتات خام (للملفات الثنائية) |

```apl
# تجهيز: مجلد وأرشيف صغير للعمل عليهما
لو ليس موجود("المشروع"):
    انشئ_مجلدات("المشروع")
اكتب("المشروع/README.md", "# مشروع تجريبي\n")
أنشئ_أرشيف("نسخة.zip", ["المشروع"])

# بافتراض أن نسخة.zip أُنشئت في القسم السابق
اطبع نص_العضو("نسخة.zip", "المشروع/README.md")

# الملفات الثنائية تُقرأ كبايتات
المتغير صورة = بايتات_العضو("نسخة.zip", "المشروع/README.md")   # bytes
اطبع طول(صورة) > 0
```

> **لماذا `read()` في دوال الكائن تُرجع بايتات والنص هنا لا؟** لأن دالة الكائن
> `.اقرأ_عضو` تطابق `ZipFile.read` حرفياً (بايتات)، أما `نص_العضو` فهي مساعد
> عربي يضيف فك ترميز UTF-8 — استخدم الاسم الذي يصف ما تحتاجه.

## 5. دوال الكائن على الأرشيف (ZipFile)

| العربي | Python | الوصف |
|--------|--------|-------|
| `.اقرأ_عضو(اسم)` | `.read` | بايتات العضو |
| `.اكتب_عضو(اسم, بيانات)` | `.writestr` | كتابة عضو جديد من نص أو بايتات |
| `.افتح_عضو(اسم, وضع)` | `.open` | مقبض ملف داخل الأرشيف |
| `.أسماء_الأعضاء()` | `.namelist` | قائمة الأسماء |
| `.سرد_الأعضاء()` | `.infolist` | قائمة `ZipInfo` |
| `.معلومات_عضو(اسم)` | `.getinfo` | بيانات عضو واحد |
| `.استخرج_عضو(اسم, مجلد)` | `.extract` | استخراج عضو |
| `.استخرج_الكل(مجلد)` | `.extractall` | استخراج الكل |
| `.عين_كلمة_السر(كلمة)` | `.setpassword` | كلمة سر للأرشيفات المشفّرة |
| `.افحص_السلامة()` | `.testzip` | `لا_شيء` = كل الأعضاء سليمة |
| `.أغلق_الأرشيف()` | `.close` | إغلاق |

```apl
المتغير الأرش = افتح_أرشيف("نسخة.zip", "a")
الأرش.اكتب_عضو("سجل.txt", "مرحباً من APL")
الأرش.اكتب_عضو("بيانات/نسخة.txt", "بيانات")
الأرش.أغلق_الأرشيف()
```

> `افحص_السلامة()` تُرجع `لا_شيء` عند السلامة، أو **اسم أول عضو تالف** — لذلك
> تستخدم داخل `لو` هكذا: `لو الأرش.افحص_السلامة() == لا_شيء:`.
>
> الإضافة بتعديل أرشيف موجود تحتاج وضع `"a"`؛ الأرشيف المفتوح على `"r"`
> للقراءة فقط ويرفض الكتابة.

## 6. خصائص الأعضاء (ZipInfo)

تُستخدم **بدون** أقواس بعد النقطة.

| العربي | Python | الوصف |
|--------|--------|-------|
| `.اسم_العضو` | `.filename` | اسم العضو داخل الأرشيف |
| `.حجم_العضو` | `.file_size` | الحجم قبل الضغط |
| `.حجم_مضغوط` | `.compress_size` | الحجم بعد الضغط |
| `.تاريخ_العضو` | `.date_time` | `(سنة, شهر, يوم, ساعة, دقيقة, ثانية)` |
| `.طريقة_الضغط` | `.compress_type` | `0` تخزين، `8` deflate، `12` bz2، `14` lzma |
| `.تعليق_الأرشيف` | `.comment` | تعليق الأرشيف (بايتات) |

```apl

لكل عضو في الأرش.سرد_الأعضاء():
    اطبع عضو.اسم_العضو + " | " + نص(عضو.حجم_العضو) + " ← " + نص(عضو.حجم_مضغوط)
المتغير الأول = الأرش.معلومات_عضو("المشروع/README.md")
اطبع الأول.تاريخ_العضو        # (سنة, شهر, يوم, ساعة, دقيقة, ثانية)
الأرش.أغلق_الأرشيف()
```

## 7. أرشيف TAR

| العربي | Python | الوصف |
|--------|--------|-------|
| `أنشئ_طر(ملف, عناصر, وضع)` | `tarfile.open(w)` | إنشاء (بدون ضغط افتراضياً) |
| `أضف_للطر(ملف, عناصر)` | `tarfile.open(a)` | إضافة أعضاء |
| `افحص_طر(ملف)` | `is_tarfile` | هل هو TAR صالح؟ |
| `افتح_طر(ملف, وضع)` | `tarfile.open` | كائن `TarFile` |
| `أرشيف_طر(ملف, وضع)` | `tarfile.open` | نفس `افتح_طر` (اسم بديل) |
| `أسماء_الطر(ملف)` | `getnames` | كل الأسماء |
| `أعضاء_الطر(ملف)` | `getmembers` | كل `TarInfo` |
| `بيانات_عضو_طر(ملف, اسم)` | `getmember` | `TarInfo` لعضو |
| `نص_من_الطر(ملف, اسم)` | `extractfile` | نص العضو |
| `استخرج_طر(ملف, إلى)` | `extractall` | استخراج آمن |

**دوال الكائن:** `.أسماء_أعضاء_الطر()` (`getnames`)، `.أعضاء_الطر_كامل()`
(`getmembers`)، `.معلومات_عضو_طر(اسم)` (`getmember`)، `.افتح_عضو_طر(اسم)`
(`extractfile`)، `.استخرج_عضو_طر()`، `.استخرج_طر_الكل()`، `.أضف_ملف_للطر()`،
`.سرد_طر()`، `.أغلق_طر()`.

**خصائص `TarInfo`:** `.اسم_الطر` (`name`)، `.مسار_الطر` (`path`)،
`.حجم_الطر` (`size`)، `.وقت_الطر` (`mtime`)، `.نمط_الطر` (`mode`)،
`.نوع_الطر` (`type` — بايت واحد مثل `b'0'`).

```apl
اكتب("تقرير.txt", "تقرير الشهر\n")
أنشئ_طر("نصوص.tar.gz", ["تقرير.txt"], طر_مع_gz)
اطبع نص_من_الطر("نصوص.tar.gz", "تقرير.txt")
استخرج_طر("نصوص.tar.gz", "خارج")

لكل عضو في أعضاء_الطر("نصوص.tar.gz"):
    اطبع عضو.اسم_الطر + " — " + حجم_بشري(عضو.حجم_الطر)
```

> TAR لا يقبل الإضافة على أرشيف **مضغوط** (`tar.gz`)، تماماً كأداة `tar` نفسها:
> فك الضغط ثم أضف ثم أعد الضغط، أو استخدم `أنشئ_طر` من جديد.

## 8. الضغط المباشر: gzip / bz2 / xz

| العربي | Python | المستوى |
|--------|--------|---------|
| `ضغط_نص(نص)` / `ضغط_سريع(نص)` / `ضغط_gz(نص)` | `gzip.compress` | سريع، منتشر |
| `فك_ضغط_نص(بايتات)` / `فك_ضغط_سريع` / `فك_ضغط_gz` | `gzip.decompress` | — |
| `ضغط_قوي(نص)` / `ضغط_bz2(نص)` | `bz2.compress` | أبطأ، أصغر |
| `فك_ضغط_قوي` / `فك_ضغط_bz2` | `bz2.decompress` | — |
| `ضغط_فائق(نص)` / `ضغط_xz(نص)` | `lzma.compress` | الأصغر، الأبطأ |
| `فك_ضغط_فائق` / `فك_ضغط_xz` | `lzma.decompress` | — |

الدوال تقبل نصاً أو بايتات، وتُرجع **بايتات** عند الضغط و**نصاً** عند الفك
(بترميز UTF-8). ومعامل `درجة_الضغط` يضبط المستوى.

```apl
المتغير نص_كبير = "بيانات متكررة " * 1000

المتغير مضغوط_نص = ضغط_نص(نص_كبير)                      # بايتات
اطبع حجم_بشري(طول(مضغوط_نص))                          # 65 بايت
اطبع فك_ضغط_نص(مضغوط_نص) == نص_كبير                   # True

المتغير سريع = ضغط_نص(نص_كبير, درجة_الضغط = أسرع_ضغط)   # 1
المتغير أقصى = ضغط_نص(نص_كبير, درجة_الضغط = أقصى_ضغط)   # 9
```

## 9. ملفات مضغوطة على القرص

| العربي | Python | الوصف |
|--------|--------|-------|
| `اكتب_مضغوط(مسار, نص)` | `gzip.open(wt)` | كتابة ملف `.gz` |
| `اقرأ_مضغوط(مسار)` | `gzip.open(rt)` | قراءة ملف `.gz` كاملاً |
| `ضغط_ملف(مسار)` | `gzip` + `copyfileobj` | يضغط أي ملف إلى `ملف.gz` |
| `فك_ملف_مضغوط(مسار, إلى)` | `gzip.open` | يفك إلى ملف عادي |
| `اكتب_bz2` / `اقرأ_bz2` | `bz2.open` | ملفات `.bz2` |
| `اكتب_xz` / `اقرأ_xz` | `lzma.open` | ملفات `.xz` |

```apl
اكتب_مضغوط("سجل.txt.gz", "أول سطر\nثاني سطر\n")
اطبع اقرأ_مضغوط("سجل.txt.gz")

# ضغط ملف موجود كما هو ثم استعادته
اكتب("بيانات.raw", "محتوى خام " * 50)
المتغير مضغوط = ضغط_ملف("بيانات.raw")        # بيانات.raw.gz
اطبع نوع_الأرشيف(مضغوط)                      # GZIP
فك_ملف_مضغوط(مضغوط, "بيانات_مستعادة.raw")
اطبع اقرأ("بيانات_مستعادة.raw")[0:12]
```

## 10. الثوابت

| العربي | Python | القيمة |
|--------|--------|--------|
| `بدون_ضغط` | `zipfile.ZIP_STORED` | 0 — تخزين بلا ضغط |
| `ضغط_افتراضي` | `zipfile.ZIP_DEFLATED` | 8 — deflate (الأنسب عموماً) |
| `ضغط_أرشيف_bz2` | `zipfile.ZIP_BZIP2` | 12 |
| `ضغط_أرشيف_lzma` | `zipfile.ZIP_LZMA` | 14 |
| `طر_بدون_ضغط` | `"w"` | أرشيف tar عادي |
| `طر_مع_gz` | `"w:gz"` | tar + gzip |
| `طر_مع_bz2` | `"w:bz2"` | tar + bz2 |
| `طر_مع_xz` | `"w:xz"` | tar + xz |
| `طر_اقرأ_تلقائي` | `"r:*"` | قراءة أي نوع ضغط تلقائياً |
| `أقصى_ضغط` | `9` | أعلى مستوى |
| `أسرع_ضغط` | `1` | أدنى مستوى |

```apl
المتغير أ = افتح_أرشيف("صغير.zip", "w", ضغط_افتراضي)
أ.اكتب_عضو("سجل.txt", "بيانات")
أ.أغلق_الأرشيف()

اكتب("سجل.txt", "بيانات السجل\n")
أنشئ_طر("أرشيف.tar.gz", ["سجل.txt"], طر_مع_gz)
المتغير مقروء_طر = افتح_طر("أرشيف.tar.gz", طر_اقرأ_تلقائي)
اطبع مقروء_طر.أسماء_أعضاء_الطر()
مقروء_طر.أغلق_طر()
```

## 11. المعاملات العربية (Keyword Arguments)

| العربي | Python |
|--------|--------|
| `درجة_الضغط = 9` | `compresslevel=9` |
| `كلمة_السر = "..."` | `pwd=...` |


## 13. الأمان والملاحظات

- **zip-slip محجوب** في كل مسارات الاستخراج (`ZIP` و`TAR`).
- **TAR:** يُستخرج بمرشّح `filter="data"` على Python 3.12+، فيمنع الملفات الخاصة
  والمسارات الخطِرة تلقائياً.
- **الأرشيفات المشفّرة:** ZIP التقليدي يدعم فقط كلمة سر ضعيفة (legacy)،
  و`عين_كلمة_السر` تخدم الأرشيفات التي أنشأتها أدوات أخرى؛ لا تعتبرها تشفيراً
  آمناً — استخدم `ضغط_فائق` مع أداة تشفير حقيقية عند الحاجة.
- **الملفات الكبيرة:** الدوال المساعدة تقرأ العضو كاملاً في الذاكرة. للملفات
  الضخمة افتح مقبضاً: `.افتح_عضو(الاسم)` واقرأ على دفعات.
- **الأحجام العربية:** `حجم_بشري` يستخدم وحدات عربية (`بايت`, `ك.ب`, `م.ب`).
- **لا شيء يُحمَّل عبثاً:** كل دالة تستورد وحدتها لحظة استدعائها، وبرنامج لا
  يستخدم الأرشيف لا يدفع أي كلفة إقلاع.

## 14. أسئلة شائعة

**س: ما الفرق بين ZIP و TAR؟**
ZIP يضغط كل عضو على حدة (تستطيع قراءة عضو واحد بسرعة)، TAR يجمع الملفات أولاً
ثم يضغط المجموع (`tar.gz`) — أفضل لنسب الضغط، وأبطأ للوصول العشوائي.

**س: أي خوارزمية أختار؟**
`gzip` للسرعة والتوافق، `bz2` لتوازن جيد، `xz` لأصغر حجم (أرشيفات التوزيع).

**س: كيف أضيف ملفاً لأرشيف مضغوط؟**
في ZIP: `أضف_للأرشيف` مباشرة (يدعم وضع `"a"`). في TAR المضغوط: لا يمكن،
فأعد إنشاء الأرشيف.

**س: لماذا `بدون_ضغط` و`ضغط_افتراضي` أعداد؟**
لأنها قيم `zipfile` نفسها: `0` و`8` و`12` و`14`. تمريرها لـ `افتح_أرشيف`
يحدد طريقة ضغط كل عضو.

**س: هل تعمل مع أرشيفات ويندوز؟**
نعم، ZIP قياسي. لكن أسماء الملفات العربية داخله تُخزَّن بترميز UTF-8،
وبعض الأدوات القديمة تعرضها مشوّشة — هذا قيد الصيغة لا المكتبة.

**س: هل يوجد تعارض مع مكتبات أخرى؟**
لا. تم فحص الـ 101 مفتاحاً آلياً ضد المكتبات الـ 42 الأخرى وعناصر اللغة الأساسية:
صفر تعارض، وترجمة الأمثلة الـ 53 السابقة لم تتغيّر بحرف واحد بعد إضافة المكتبة. الأسماء المحجوزة في مكتبات أخرى (`ضغط`, `مستوى`, `هو_مجلد`, `وضع`)
لم تُستخدم هنا؛ استُبدلت بـ `درجة_الضغط`, `عضو_مجلد`, `ضغط_افتراضي`, إلخ.
