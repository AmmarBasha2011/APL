# مكتبة Flask — إطار عمل ويب بالعربي

مكتبة Flask الكاملة بالعربي، إطار عمل ويب:

## إنشاء التطبيق

| العربي | Python | الوصف |
|--------|--------|-------|
| `فلاسك(اسم)` | `Flask(اسم)` | إنشاء تطبيق Flask |
| `تطبيق_فلاسك(اسم)` | `Flask(اسم)` | إنشاء تطبيق Flask |
| `خدمة_ويب(اسم)` | `Flask(اسم)` | إنشاء تطبيق ويب |

## المسارات (Routing)

| العربي | Python | الوصف |
|--------|--------|-------|

## التعامل مع الطلب (Request)

| العربي | Python | الوصف |
|--------|--------|-------|
| `طلب` | `request` | كائن الطلب |
| `طلب_جيت('مفتاح')` | `request.args.get('مفتاح')` | معاملات GET |
| `طلب_نموذج('حقل')` | `request.form['حقل']` | بيانات النموذج |
| `طلب_ملف('اسم')` | `request.files['اسم']` | ملف مرفوع |
| `طلب_رأس('اسم')` | `request.headers['اسم']` | رأس الطلب |
| `طلب_كوكي('اسم')` | `request.cookies.get('اسم')` | كوكي |
| `طلب_جلسة` | `session` | جلسة المستخدم |
| `طلب_طريقة` | `request.method` | طريقة الطلب |
| `طلب_مسار` | `request.path` | مسار الطلب |
| `طلب_عنوان` | `request.url` | عنوان الطلب |
| `طلب_أي_بي` | `request.remote_addr` | IP العميل |
