# مكتبة نسخ ونقل الملفات — `shutil`

أدوات نسخ ونقل وحذف الملفات والمجلدات من مكتبة `shutil` في Python، مترجمة بالكامل.

12 دالة

## الدوال

| العربي | Python | الوصف |
|--------|--------|-------|
| `انسخ_ملف(...)` | `shutil.copy` | نسخ ملف |
| `انسخ_ملف_كامل(...)` | `shutil.copy2` | نسخ مع الأذونات والأوقات |
| `انسخ_شجرة(...)` | `shutil.copytree` | نسخ مجلد كامل بمحتوياته |
| `انقل_ملف(...)` | `shutil.move` | نقل أو إعادة تسمية |
| `احذف_شجرة(...)` | `shutil.rmtree` | حذف مجلد ومحتوياته |
| `نسخ_محتوى(...)` | `shutil.copyfile` | نسخ محتوى الملف فقط |
| `الحجم_البشري(...)` | `shutil.disk_usage` | مساحة القرص |
| `ابحث_في_المسار(...)` | `shutil.which` | أين يوجد البرنامج؟ |
| `أمر_النظام(...)` | `shutil.which` | اسم بديل |
| `انسخ_الصلاحيات(...)` | `shutil.copymode` | نسخ أذونات التنفيذ |
| `انسخ_البيانات(...)` | `shutil.copyfileobj` |  |
| `تجاهل_الملفات(...)` | `shutil.ignore_patterns` | أنماط تجاهل عند نسخ شجرة |

## أمثلة

```apl
# إعداد ملفات للتجربة
أنشئ_مجلد_مسار(مسار_جديد("مجلد"), آباء=صواب, موجود_سلفا=صواب)
مسار_اكتب(مسار_جديد("مجلد/داخل.txt"), "محتوى")

# نسخ ملف ومجلد
انسخ_ملف("مجلد/داخل.txt", "نسخة.txt")
انسخ_شجرة("مجلد", "نسخة_المجلد")
اطبع "نسخة المجلد:", مسار_موجود(مسار_جديد("نسخة_المجلد"))

# نقل
انقل_ملف("نسخة.txt", "المكان_الجديد.txt")
اطبع "بعد النقل:", مسار_موجود(مسار_جديد("المكان_الجديد.txt"))

# تنظيف
احذف_شجرة("نسخة_المجلد")
مسار_احذف(مسار_جديد("مجلد/داخل.txt"))
مسار_احذف(مسار_جديد("المكان_الجديد.txt"))

# البحث عن البرامج ومساحة القرص
اطبع "بايثون:", ابحث_في_المسار("python")
اطبع "القرص:", الحجم_البشري(".")
```
