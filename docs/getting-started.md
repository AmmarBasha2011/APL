# دليل البداية — من التثبيت إلى أول برنامج

هذا الدليل يمشي بك خطوة خطوة: تثبّت، تكتب، تشغّل، تقرأ الناتج، وتفهم أين كل شيء في المشروع.

## 1. ما تحتاجه

- **Python 3.14 أو أحدث** — هذا كل شيء. نواة اللغة لا تحتاج أي مكتبة خارجية.
- مكتبات معيّنة (ويب، علمي، بوتات) تحتاج حزمها فقط عندما تستعملها فعلاً (انظر قسم «المكتبات» أدناه).

## 2. التثبيت

```bash
git clone https://github.com/AmmarBasha2011/APL.git
cd APL
```

تستطيع التشغيل فوراً بدون أي تثبيت:

```bash
python apl.py -c "اطبع 'مرحباً'"
```

أو ثبّت اللغة كحزمة لتحصل على الأمر `apl` (مستحسن داخل بيئة افتراضية):

```bash
python -m venv .venv
. .venv/bin/activate
pip install .
apl --version
```

حزم اختيارية حسب حاجتك: `pip install '.[web]'` أو `'.[science]'` أو `'.[bots]'`.

## 3. أول برنامج في دقيقة

أنشئ ملفاً باسم `مرحبا.apl` في أي مكان تريده:

```apl
المتغير اسم = "يا صديقي"
اطبع "أهلاً", اسم

لكل i في نطاق(1, 4):
    اطبع "سطر رقم:", i
```

شغّله:

```bash
python apl.py مرحبا.apl
```

الناتج يظهر في الطرفية مباشرة:

```
أهلاً يا صديقي
سطر رقم: 1
سطر رقم: 2
سطر رقم: 3
```

## 4. أين تكتب الكود

- **أي ملف `.apl` في أي مجلد** — اللغة لا تفرض مكاناً. ملفك ملكك.
- `examples/` — 511 مثالاً جاهزاً للتعلم والنسخ، كلها مختبرة في كل فحص.
- `projects/` — مشاريع كاملة متعددة الملفات (مثل `taskbook` و `treasure-game`) تصلح قوالب لمشروعك.

## 5. طرق التشغيل

| الأمر | ماذا يفعل |
|-------|-----------|
| `python apl.py ملف.apl` | تشغيل ملف (بدون تثبيت) |
| `apl run ملف.apl وسائط...` | تشغيل ملف مع تمرير وسائط (بعد `pip install .`) |
| `python apl.py -c "كود"` | تنفيذ كود مباشرة من سطر الأوامر |
| `python apl.py repl` | REPL تفاعلي، جرّب سطراً بسطر |
| `apl check ملف.apl` | فحص الصياغة بدون تشغيل |
| `apl transpile ملف.apl` | عرض كود Python المولَّد |

## 6. أين يظهر الناتج

- **الطباعة** (`اطبع`) تذهب إلى الطرفية مباشرة.
- **الملفات** التي يكتبها برنامجك (`اكتب`، `احفظ`...) تُنشأ حيث حدّدت أنت في الكود.
- **كود Python المولَّد** يُخزَّن مؤقتاً في مجلد `__pycache__` بجانب ملف `.apl` لتسريع التشغيل التالي. لرؤيته بنفسك: `apl transpile ملف.apl`.
- لمسح الذاكرة المؤقتة: `python apl.py --clear-cache`.

## 7. عندما يحدث خطأ

الأخطاء تظهر **بالعربية** مع موضع الخطأ، مسبوقة ببادئة ثابتة مثل `APL-ValueError` تصلح للبحث والفرز:

```
APL-ValueError في ملف مرحبا.apl، السطر 3
خطأ في القيمة: ...
```

لو احتجت تفاصيل Python الكاملة: `apl run --debug ملف.apl`.
قائمة كل رسائل الأخطاء المترجمة: [error-messages.md](error-messages.md).

## 8. خريطة المشروع

| المجلد/الملف | ما فيه |
|---------------|--------|
| `apl.py` | نقطة التشغيل المباشرة |
| `core/` | محرك اللغة: المترجم والمكتبات العربية |
| `examples/` | 511 مثالاً جاهزاً، كلها مختبرة |
| `projects/` | مشاريع كاملة متعددة الملفات |
| `docs/` | التوثيق الكامل (أنت هنا) |
| `tests/` | اختبارات النواة |
| `test_examples.py` | يشغّل كل الأمثلة ويتأكد أنها تعمل |
| `scripts/` | فحوص الجودة التي تعمل في CI |
| `website/` | الموقع الثابت، يُبنى بـ `python website/build.py` |
| `benchmarks/` | قياسات الأداء وتقريرها |
| `editors/` | دعم المحررات (VS Code) |
| `playground/` | ساحة تجربة معزولة اختيارية |

## 9. دورة العمل اليومية

1. **اكتب** كودك في ملف `.apl`.
2. **شغّل**: `python apl.py ملف.apl`.
3. **اقرأ** الناتج في الطرفية؛ لو فيه خطأ، الرسالة بالعربية وتدلّك على السطر.
4. **صحّح** وأعد التشغيل — الذاكرة المؤقتة تجعل الإعادة سريعة.
5. مشروعك كبر؟ استخدم `apl check` للفحص السريع، واكتب اختبارات مثل `projects/treasure-game/test_game.py`.
