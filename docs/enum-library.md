# مكتبة enum — الأنواع المعدودة (Enums)

أنواع معدودة: مجموعة قيم مسمّاة وثابتة، بدل الأرقام السحرية.

## التوقيع

```apl
المتغير حالة = نوع_تعداد("حالة", "نشط، معطل، pending")
```

| الوسيط | النوع | الوصف |
|---|---|---|
| `الاسم` | نص | اسم النوع (يظهر في أخطاء Python) |
| `المواصفات` | نص | الأسماء مفصولة بفاصلة `،` أو `,` |

القيم تُرقَّم تلقائيًا من **1** بالترتيب المُعطى.

## الدوال

| الدالة | الوصف | مثال |
|---|---|---|
| `نوع_تعداد(اسم, مواصفات)` | إنشاء نوع معدود | `نوع_تعداد("حالة", "نشط، معطل")` |
| `كل_الأسماء(النوع)` | قائمة بكل الأسماء | `كل_الأسماء(حالة)` |
| `كل_القيم(النوع)` | قائمة بكل القيم | `كل_القيم(حالة)` |
| `قيمة_من_اسم(النوع, اسم)` | القيمة من الاسم | `قيمة_من_اسم(حالة, "نشط")` |
| `تحقق_من_القيمة(النوع, رقم)` | هل القيمة موجودة؟ | `تحقق_من_القيمة(حالة, 2)` |

## الخصائص

| الخاصية | الوصف |
|---|---|
| `.name` | اسم العنصر |
| `.value` | قيمة العنصر |

## مثال كامل — يعمل

```apl
المتغير حالة = نوع_تعداد("حالة", "نشط، معطل، pending")

اطبع "الاسم:", حالة.نشط.name
اطبع "القيمة:", حالة.نشط.value
اطبع "كل الأسماء:", كل_الأسماء(حالة)
اطبع "كل القيم:", كل_القيم(حالة)
اطبع "هل 2 موجود؟", تحقق_من_القيمة(حالة, 2)
اطبع "قيمة معطل:", قيمة_من_اسم(حالة, "معطل")
```

**الناتج:**

```
الاسم: نشط
القيمة: 1
كل الأسماء: ['نشط', 'معطل', 'pending']
كل القيم: [1, 2, 3]
هل 2 موجود؟ True
قيمة معطل: 2
```

## مثال — حالات الطلب

```apl
المتغير طلب = نوع_تعداد("طلب", "جديد، قيد_المعالجة، مُكتمل، ملغي")

لكل حالة_حالية في [طلب.جديد, طلب.مُكتمل, طلب.ملغي]:
    اطبع حالة_حالية.name + " → " + نص(حالة_حالية.value)
```

```
جديد → 1
مكتمل → 3
ملغي → 4
```

## لماذا تستحق بدل الأرقام

بدون enum — الأرقام السحرية:

```apl
المتغير الحالة = 1
إذا الحالة == 1:
    اطبع "طلب جديد"
```


مع enum:

```apl
المتغير حالة = نوع_تعداد("حالة", "جديد، قيد_المعالجة، مُكتمل")
المتغير الحالة = حالة.جديد

إذا الحالة == حالة.جديد:
    اطبع "طلب جديد"
# تغيير الاسم لاحقًا لا يكسر شيئًا، والـ autocomplete يعمل
```

## ملاحظات

- المفتاح `تعداد` يبقى مرتبطًا بـ `enum.Enum` من مكتبة `dataclasses`؛ استخدم `نوع_تعداد` لإنشاء النوع كاملًا.
- أسماء العناصر العربية معرّفات Python صالحة، فتُكتب مباشرة: `حالة.نشط`.
- فاصل الفاصلة يدعم العربي `،` والإنجليزي `,`.
- تحت hood: `enum.Enum` القياسي من مكتبة Python.
