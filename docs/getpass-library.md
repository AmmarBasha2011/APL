# مكتبة كلمات السر المخفية — `getpass`

إدخال كلمات السر دون إظهارها على الشاشة.

**2 عنصر** (2 دالة).

## الدوال

| العربي | Python | الوصف |
|--------|--------|-------|
| `كلمة_سر_مخفية(...)` | `getpass.getpass` | إدخال مخفي |
| `اسم_المستخدم_الحالي(...)` | `getpass.getuser` | اسم مستخدم النظام |

## أمثلة

```apl
# كلمة_سر_مخفية("كلمة السر: ") لا تعرض ما تكتبه
اطبع "المستخدم الحالي:", اسم_المستخدم_الحالي()
```
