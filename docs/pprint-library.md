# مكتبة الطباعة الجميلة — `pprint`

طباعة القواميس والقوائم النصوصية بشكل منسّق ومقروء.

**2 عنصر** (2 دالة).

## الدوال

| العربي | Python | الوصف |
|--------|--------|-------|
| `طباعة_جميلة(...)` | `pprint.pprint` | طباعة منسّقة |
| `طباعة_نص_جميل(...)` | `pprint.pformat` | إرجاع النص المنسّق |

## أمثلة

```apl
المتغير البيانات = {"الاسم": "عمار", "السنة": 2026, "المدن": ["القاهرة", "الإسكندرية"]}

طباعة_جميلة(البيانات)
اطبع "طول النص المنسّق:", طول(طباعة_نص_جميل(البيانات)) > 0
```
