وترميزها، ثوابت وحالات HTTP، رسائل البريد وعناوينها وسياساتها، صناديق البريد،
ملفات تعريف الارتباط، أنواع MIME، HTML، نداءات XML-RPC، ورؤوس WSGI، وملفات
`robots.txt`.
