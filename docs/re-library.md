# مكتبة التعابير النمطية — `re`

كل الدوال من مكتبة `re` في Python، مترجمة بالكامل:

## بحث (Searching)

| العربي | Python | الوصف |
|--------|--------|-------|
| `بحث_نمطي(نمط, نص)` | `re.search(نمط, نص)` | بحث عن النمط في النص |
| `بحث_كامل(نمط, نص)` | `re.match(نمط, نص)` | مطابقة من البداية |
| `بحث_شامل(نمط, نص)` | `re.findall(نمط, نص)` | كل التطابقات |
| `بحث_مكرر(نمط, نص)` | `re.finditer(نمط, نص)` | مكرر للتطابقات |

## استبدال (Substitution)

| العربي | Python | الوصف |
|--------|--------|-------|
| `استبدل(نمط, بديل, نص)` | `re.sub(نمط, بديل, نص)` | استبدال التطابقات |
| `استبدل_عدد(نمط, بديل, نص)` | `re.subn(نمط, بديل, نص)` | استبدال مع العدد |

## تقسيم (Splitting)

| العربي | Python | الوصف |
|--------|--------|-------|
| `قسم_نمطي(نمط, نص)` | `re.split(نمط, نص)` | تقسيم بالنمط |

## تجميع (Groups)

| العربي | Python | الوصف |
|--------|--------|-------|
| `مجموعة_نمطية(رقم)` | `re.group(رقم)` | مجموعة محددة |
| `مجموعات_نمطية()` | `re.groups()` | كل المجموعات |

## مطابقة (Matching)

| العربي | Python | الوصف |
|--------|--------|-------|
| `مطابقة(نمط, نص)` | `re.fullmatch(نمط, نص)` | مطابقة كاملة |

## أخرى

| العربي | Python | الوصف |
|--------|--------|-------|
| `جمع_نمط(نمط)` | `re.compile(نمط)` | تجميع النمط (للأداء) |
| `هرب(نص)` | `re.escape(نص)` | هروب الأحرف الخاصة |

## ثوابت نمطية شائعة (Common Regex Constants)

| العربي | القيمة | الوصف |
|--------|--------|-------|
| `رقم` | `r'\d'` | رقم واحد |
| `أرقام` | `r'\d+'` | رقم أو أكثر |
| `حرف` | `r'\w'` | حرف أو رقم |
| `حروف` | `r'\w+'` | حرف أو رقم أو أكثر |
| `مسافة` | `r'\s'` | مسافة بيضاء |
| `مسافات` | `r'\s+'` | مسافة أو أكثر |
| `أي_حرف` | `r'.'` | أي حرف |
| `بداية` | `r'^'` | بداية النص |
| `نهاية` | `r'$'` | نهاية النص |
| `نقطة` | `r'\.'` | نقطة (حرف حرفي) |
| `نجمة` | `r'\*'` | نجمة (حرف حرفي) |
| `زائد` | `r'\+'` | زائد (حرف حرفي) |
| `علامة_استفهام` | `r'\?'` | علامة استفهام (حرف حرفي) |

## مثال

```apl
المتغير نص = "Hello World 123"

# بحث
النتيجة = بحث_نمطي(رقم, نص)
if النتيجة:
    print("Found:", النتيجة.group())

# كل التطابقات
النتائج = بحث_شامل(رقم, نص)
print("All numbers:", النتائج)

# استبدال
الجديد = استبدل(رقم, "X", نص)
print("Replaced:", الجديد)

# مطابقة كاملة
if مطابقة(حروف, "Hello"):
    print("Match!")
```
