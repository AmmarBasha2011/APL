# مكتبة التعابير النمطية — `re`

أدوات التعابير النمطية في Python، مترجمة بالكامل إلى العربية.

**12 دالة و 13 ثابت**

## الدوال

| العربي | Python | الوصف |
|--------|--------|-------|
| `بحث_نمطي(...)` | `re.search` | re.search — أول مطابقة في أي مكان |
| `بحث_كامل(...)` | `re.match` | re.match — من بداية النص |
| `بحث_شامل(...)` | `re.findall` | re.findall — كل المطابقات |
| `بحث_مكرر(...)` | `re.finditer` | re.finditer — مولّد المطابقات |
| `استبدل(...)` | `re.sub` | re.sub — استبدال نمط |
| `استبدل_عدد(...)` | `re.subn` | re.subn — استبدال مع عدّ |
| `قسم_نمطي(...)` | `re.split` | re.split — تقسيم بنمط |
| `مجموعة_نمطية(...)` | `re.group` | re.group — مجموعة |
| `مجموعات_نمطية(...)` | `re.groups` | re.groups — كل المجموعات |
| `مطابقة(...)` | `re.fullmatch` | re.fullmatch — مطابقة كاملة |
| `جمع_نمط(...)` | `re.compile` | re.compile — تجميع نمط |
| `هرب(...)` | `re.escape` | re.escape — تهريب محارف |

## ثوابت نمطية (Regex Constants)

أسماءها مبدوءة بـ `نمط_` لتفادي التعارض مع الكود العادي.

| العربي | القيمة | الوصف |
|--------|--------|-------|
| `نمط_رقم` | `r'\d'` | رقم واحد |
| `نمط_أرقام` | `r'\d+'` | رقم أو أكثر |
| `نمط_حرف` | `r'\w'` | حرف أو رقم |
| `نمط_حروف` | `r'\w+'` | حرف أو رقم أو أكثر |
| `نمط_مسافة` | `r'\s'` | مسافة بيضاء |
| `نمط_مسافات` | `r'\s+'` | مسافة أو أكثر |
| `نمط_أي_حرف` | `r'.'` | أي حرف |
| `نمط_بداية` | `r'^'` | بداية النص |
| `نمط_نهاية` | `r'$'` | نهاية النص |
| `نمط_نقطة` | `r'\.'` | نقطة (حرف حرفي) |
| `نمط_نجمة` | `r'\*'` | نجمة (حرف حرفي) |
| `نمط_زائد` | `r'\+'` | زائد (حرف حرفي) |
| `نمط_علامة_استفهام` | `r'\?'` | علامة استفهام (حرف حرفي) |

## أمثلة

```apl
# النمط أولاً ثم النص
اطبع "بحث:", بحث_نمطي("ell", "hello")
اطبع "كل المطابقات:", بحث_شامل("l", "hello")
اطبع "استبدال:", استبدل("l", "L", "hello")
اطبع "تقسيم:", قسم_نمطي(",", "a,b,c")
اطبع "مطابقة كاملة:", مطابقة("h.*o", "hello") != لا_شيء

# الثوابت النمطية
اطبع "رقم واحد:", نمط_رقم
اطبع "أرقام:", نمط_أرقام
اطبع "أي حرف:", نمط_أي_حرف
```
