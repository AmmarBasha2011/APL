# مكتبة التعابير النمطية — `re`

أدوات التعابير النمطية في Python، مترجمة بالكامل إلى العربية.

**12 دالة و 13 ثابت**

**25 عنصراً عربياً** (الدوال: 12، الثوابت: 13).

## الدوال (12)

| العربي | Python |
|--------|--------|
| `بحث_نمطي` | `re.search` |
| `بحث_كامل` | `re.match` |
| `بحث_شامل` | `re.findall` |
| `بحث_مكرر` | `re.finditer` |
| `استبدل` | `re.sub` |
| `استبدل_عدد` | `re.subn` |
| `قسم_نمطي` | `re.split` |
| `مجموعة_نمطية` | `re.group` |
| `مجموعات_نمطية` | `re.groups` |
| `مطابقة` | `re.fullmatch` |
| `جمع_نمط` | `re.compile` |
| `هرب` | `re.escape` |

## مثال

```apl
# النمط أولاً ثم النص
اطبع "بحث:", بحث_نمطي("ell", "hello")
اطبع "كل المطابقات:", بحث_شامل("l", "hello")
اطبع "استبدال:", استبدل("l", "L", "hello")
اطبع "تقسيم:", قسم_نمطي(",", "a,b,c")
اطبع "مطابقة كاملة:", مطابقة("h.*o", "hello") != لا_شيء

# الثوابت النمطية
اطبع "رقم واحد:", نمط_رقم
اطبع "أرقام:", نمط_أرقام
اطبع "أي حرف:", نمط_أي_حرف
```
