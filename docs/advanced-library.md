# المكتبة المتقدمة — Advanced Features

مكتبة الميزات المتقدمة في Python بالعربي:

## Decorators متقدمة

| العربي | Python | الوصف |
|--------|--------|-------|
| `@wraps_دالة(دالة)` | `functools.wraps(دالة)` | الحفاظ على البيانات الوصفية |
| `@يلتف(دالة)` | `functools.wraps(دالة)` | يلتف (عربي) |
| `@كاش_دالة` | `functools.cache` | تخزين مؤقت |
| `@خاصية_مخزنة_دالة` | `functools.cached_property` | خاصية مخزنة |
| `@توزيع_فردي` | `functools.singledispatch` | توزيع فردي |

## أمثلة

```apl
# Decorator
@wraps_دالة(دالة_أصلية)
def دالة_جديدة(*args, **kwargs):
    return دالة_أصلية(*args, **kwargs)

# Generator
دالة أرقام(نهاية):
    لكل i في نطاق(نهاية):
        ولد i  # yield i

# Context Manager
مع فتح("ملف.txt") مثل f:
    اطبع f.read()

# Heap
المتغير h = []
كومة_دفعة(h, 3)
كومة_دفعة(h, 1)
كومة_دفعة(h, 2)
اطبع كومة_سحب(h)  # 1

# Multiprocessing
عملية_جديدة(هدف=دالة_العاملة)

# ThreadPoolExecutor
مع مجموعة_ثريدات() مثل executor:
    المستقبل = executor.submit(دالة, وسيط)
    النتيجة = مستقبل_عند_اكتمال

# TypeVar
متغير_نوع_عام = متغير_نوع_عام('T')

# TypedDict
class مستخدم(قاموس_مهيكل_عام):
    اسم: نص
    عمر: عدد_صحيح
```
