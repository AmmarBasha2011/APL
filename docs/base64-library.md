# مكتبة الترميز — `base64`

ترميز البيانات النصية إلى صيغ نقل آمنة (base64).

**10 عنصر** (10 دالة، 0 خاصية).

## الدوال

| العربي | Python | الوصف |
|--------|--------|-------|
| `ترميز_قاعد64(...)` | `base64.b64encode` | ترميز base64 |
| `فك_ترميز_قاعد64(...)` | `base64.b64decode` | فك الترميز |
| `ترميز_آمن_للروابط(...)` | `base64.urlsafe_b64encode` | base64 آمن للروابط |
| `فك_ترميز_آمن(...)` | `base64.urlsafe_b64decode` | فك الترميز الآمن |
| `ترميز_أسطر(...)` | `base64.encodebytes` | base64 مع أسطر |
| `فك_ترميز_أسطر(...)` | `base64.decodebytes` | فك الترميز |
| `ترميز_سداسي(...)` | `base64.b16encode` | Base16 |
| `فك_ترميز_سداسي(...)` | `base64.b16decode` | فك Base16 |
| `ترميز_أساس_32(...)` | `base64.b32encode` | Base32 |
| `فك_ترميز_أساس_32(...)` | `base64.b32decode` | فك Base32 |

## أمثلة

```apl
# الترميز يتطلب bytes وليس str
المتغير مشفر = ترميز_قاعد64("سلام".encode("utf-8"))
اطبع فك_ترميز_قاعد64(مشفر).decode("utf-8")

# ترميز آمن للروابط
اطبع فك_ترميز_آمن(ترميز_آمن_للروابط(b"a+b/c?")).decode()
```
