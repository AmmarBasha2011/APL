# مكتبة نظام التشغيل — `os` + `pathlib`

كل الدوال من مكتبتين `os` و `pathlib` في Python، مترجمة بالكامل:

## مسارات (Path Operations)

| العربي | Python | الوصف |
|--------|--------|-------|
| `مسار_مطلق(مسار)` | `os.path.abspath(مسار)` | المسار المطلق |
| `مسار_نسبي(مسار)` | `os.path.relpath(مسار)` | المسار النسبي |
| `اسم_ملف(مسار)` | `os.path.basename(مسار)` | اسم الملف من المسار |
| `اسم_مجلد(مسار)` | `os.path.dirname(مسار)` | اسم المجلد |
| `امتداد(مسار)` | `os.path.splitext(مسار)` | امتداد الملف |
| `دمج_مسار(أ, ب)` | `os.path.join(أ, ب)` | دمج مسارين |
| `فصل_مسار(مسار)` | `os.path.split(مسار)` | (مجلد, ملف) |

## مجلدات (Directory Operations)

| العربي | Python | الوصف |
|--------|--------|-------|
| `مجلد_حالي()` | `os.getcwd()` | المجلد الحالي |
| `غير_مجلد(مسار)` | `os.chdir(مسار)` | تغيير المجلد |
| `انشئ_مجلد(مسار)` | `os.mkdir(مسار)` | إنشاء مجلد |
| `انشئ_مجلدات(مسار)` | `os.makedirs(مسار)` | إنشاء مجلدات متداخلة |
| `احذف_مجلد(مسار)` | `os.rmdir(مسار)` | حذف مجلد فارغ |
| `قائمة_ملفات(مسار)` | `os.listdir(مسار)` | قائمة الملفات |

## ملفات (File Operations)

| العربي | Python | الوصف |
|--------|--------|-------|
| `احذف_ملف(مسار)` | `os.remove(مسار)` | حذف ملف |
| `اعد_تسمية(ق, ج)` | `os.rename(ق, ج)` | إعادة تسمية |
| `نسخ_ملف(م, هـ)` | `shutil.copy(م, هـ)` | نسخ ملف |
| `نقل_ملف(م, هـ)` | `shutil.move(م, هـ)` | نقل ملف |
| `حجم_ملف(مسار)` | `os.path.getsize(مسار)` | حجم الملف |
| `وقت_تعديل(مسار)` | `os.path.getmtime(مسار)` | وقت آخر تعديل |

## فحص (Inspection)

| العربي | Python | الوصف |
|--------|--------|-------|
| `موجود(مسار)` | `os.path.exists(مسار)` | هل المسار موجود |
| `هو_ملف(مسار)` | `os.path.isfile(مسار)` | هل هو ملف |
| `هو_مجلد(مسار)` | `os.path.isdir(مسار)` | هل هو مجلد |
| `هو_رابط_مطلق(مسار)` | `os.path.isabs(مسار)` | هل المسار مطلق |

## بيئة (Environment)

| العربي | Python | الوصف |
|--------|--------|-------|
| `متغير_بيئة(اسم)` | `os.environ.get(اسم)` | متغير بيئة |
| `معرف_عملية()` | `os.getpid()` | معرف العملية |
| `مجلد_منزل(مسار='~')` | `os.path.expanduser(مسار)` | مجلد المستخدم |
| `فاصل_مسار` | `os.sep` | فاصل المسارات (بدون أقواس) |

## مثال

```apl
اطبع "المجلد الحالي:", مجلد_حالي()
اطبع "موجود('test.apl'):", موجود("test.apl")
اطبع "حجم_ملف('calc.apl'):", حجم_ملف("calc.apl")
اطبع "اسم_ملف('/a/b/c.txt'):", اسم_ملف("/a/b/c.txt")
اطبع "دمج_مسار('a', 'b'):", دمج_مسار("a", "b")
اطبع "فاصل_مسار:", فاصل_مسار
```
