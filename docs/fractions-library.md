# مكتبة الكسور الرياضية — `fractions`

الكسور الرياضية الدقيقة: 1/3 تساوي تماماً 0.333…

**8 عنصر** (5 دالة، 2 خاصية، 1 دالة كائن).

## الدوال

| العربي | Python | الوصف |
|--------|--------|-------|
| `كسر(...)` | `fractions.Fraction` | إنشاء كسر |
| `من_عددين(...)` | `fractions.Fraction` | كسر من بسط ومقام (يُبسّط) |
| `من_نص_كسر(...)` | `fractions.Fraction` | نص -> كسر |
| `قيمة_كسر(...)` | `_apl_fraction_value` | الكسر كـ float |
| `مقلوب_كسر(...)` | `_apl_fraction_recip` | 1/كسر |

## دوال الكائن (Methods)

تُستخدم بعد النقطة: `كسر.حد_المقام(6)`

| العربي | Python | الوصف |
|--------|--------|-------|
| `حد_المقام(...)` | `.limit_denominator` |  |

## خصائص الكائن (Properties)

تُستخدم بعد النقطة: `كسر.بسط_كسر`

| العربي | Python | الوصف |
|--------|--------|-------|
| `بسط_كسر` | `.numerator` |  |
| `مقام_كسر` | `.denominator` |  |

## أمثلة

```apl
المتغير ثلث = كسر(1, 3)
اطبع "الثلث:", نص(ثلث)
اطبع "البسط:", ثلث.بسط_كسر
اطبع "المقام:", ثلث.مقام_كسر
اطبع "3/6 = ", نص(من_عددين(3, 6))
اطبع "مقلوب 2/5 =", نص(مقلوب_كسر(كسر(2, 5)))
```
