# مكتبة تنسيق النصوص — `textwrap`

دوال لف النصوص على عرض محدد وتنسيق المسافات.

**9 عنصر** (9 دالة، 0 خاصية).

## الدوال

| العربي | Python | الوصف |
|--------|--------|-------|
| `التفاف_نص(...)` | `textwrap.fill` | لف النص على عرض محدد |
| `الالتفاف_نص(...)` | `textwrap.fill` | اسم بديل |
| `التفاف_سطر(...)` | `textwrap.wrap` | لف وإرجاع قائمة أسطر |
| `الالتفاف_سطر(...)` | `textwrap.wrap` | اسم بديل |
| `اختصار_نص(...)` | `textwrap.shorten` | اختصار مع ... في النهاية |
| `إزالة_التفافات(...)` | `textwrap.dedent` | إزالة المسافات البادئة |
| `إزاحة_نص(...)` | `textwrap.indent` | إضافة مسافة بادئة لكل سطر |
| `محاذاة_نص(...)` | `textwrap.fill` | محاذاة النص |
| `حزم_النص(...)` | `textwrap.fill` |  |

## أمثلة

```apl
المتغير نص = "السطر الطويل جدا جدا هنا ويجب أن يلف على عدة اسطر"
اطبع الالتفاف_نص(نص, 20)
اطبع اختصار_نص(نص, 30)
اطبع إزالة_التفافات("    نص بمسافة بادئة")
```
