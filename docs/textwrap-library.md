# مكتبة تنسيق النصوص — `textwrap`

دوال لف النصوص على عرض محدد وتنسيق المسافات.

**5 عنصراً عربياً** (الدوال: 9).

## الدوال (5)

| العربي | Python |
|--------|--------|
| `الالتفاف_نص` | `textwrap.fill` |
| `التفاف_سطر` | `textwrap.wrap` |
| `اختصار_نص` | `textwrap.shorten` |
| `إزالة_التفافات` | `textwrap.dedent` |
| `إزاحة_نص` | `textwrap.indent` |

## مثال

```apl
المتغير نص = "السطر الطويل جدا جدا هناIndeed يجب أن يُلف"
اطبع الالتفاف_نص(نص, 20)
اطبع اختصار_نص(نص, 30)
اطبع إزالة_التفافات("    نص بمسافة بادئة")
```
