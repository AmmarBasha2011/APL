# برومبت وكيل الذكاء الاصطناعي — اجعل الوكيل يبرمج بـ APL

هذا الملف يعطيك **برومبت جاهز للنسخ** تلصقه لأي وكيل ذكاء اصطناعي (ChatGPT، Claude، Cursor، أو غيرها) ليكتب لك مشروعاً كاملاً بلغة APL، ثم دليل قصير لاستعماله ومراجعة الناتج.

كل قاعدة في البرومبت أدناه جرى التحقق منها بتشغيلها فعلياً على هذا المستودع.

---

## البرومبت الجاهز (انسخ كل ما في الصندوق)

```text
ستكتب برنامجاً بلغة APL — لغة برمجة عربية تتحول تلقائياً إلى Python ثم تعمل.
التزم بالقواعد التالية حرفياً، فهي قواعد اللغة الحقيقية وليست اقتراحات:

## كيف تُشغَّل اللغة
- الملفات بامتداد .apl وتُشغَّل بـ: python apl.py ملف.apl
- تحتاج Python 3.14 أو أحدث. النواة بلا أي مكتبات خارجية.
- الأخطاء تظهر بالعربية مع رقم السطر وبادئة مثل APL-ValueError.

## قواعد الصياغة
- التعليق بعلامة # في نهاية السطر أو في سطر مستقل.
- الكتل بالمسافات البادئة (4 مسافات) وتنتهي الترويسة بنقطتين : مثل Python.
- أول تعريف لأي متغير يبدأ بكلمة «المتغير»: المتغير س = 5
  إعادة الإسناد لاحقاً بدونها: س = س + 1
- الطباعة: اطبع "نص", متغير    (افصل القيم بفواصل)
- الإدخال من لوحة المفاتيح: المتغير اسم = ادخل("ما اسمك؟ ")
- الشرط:
    لو س > 10:
        اطبع "كبير"
    الا لو س == 10:
        اطبع "عشرة"
    الا:
        اطبع "صغير"
- شرط ثلاثي: المتغير ن = 1 إذا صواب والا 0
- الحلقات:
    طالما س < 3:
        س = س + 1
    لكل عنصر في قائمتي:
        اطبع عنصر
- الدوال:
    دالة جمع(أ, ب):
        ارجع أ + ب
- الأصناف:
    صنف شخص:
        دالة_إنشاء(ذات, اسم):
            ذات.اسم = اسم
        دالة سلام(ذات):
            اطبع "مرحبا", ذات.اسم
- معالجة الأخطاء:
    حاول:
        المتغير س = صحيح("abc")
    إمسك:
        اطبع "رقم غير صحيح"
- القيم المنطقية: صواب / خطأ / لا_شيء
- العمليات المنطقية: و / أو / ليس

## الدوال الجاهزة الأكثر استعمالاً
- تحويل الأنواع: صحيح("42")  نص(5)  عشري("3.5")
- نطاق(5)  طول(قائمة)  مجموع(قائمة)  أكبر  أصغر  مفرز(قائمة)  عدد(قائمة)
- قوائم: قائمة()  قاموس()  مجموعة()
- نصوص (تُستدعى كنقطة على المتغير):
    نصي.تقسيم(" ")  نصي.ضم(قائمة)  نصي.علوي()  نصي.سفلي()
    نصي.تقليم()  نصي.استبدال("قديم", "جديد")  نصي.بداية("أ")  نصي.نهاية("ب")
- ملفات: المتغير محتوى = اقرأ("ملف.txt")    اكتب("ملف.txt", "نص")
- JSON: المتغير ق = جسون("{\"أ\": 1}")    جسون_تحويل(ق)
  (جسون_تحويل يهرّب الحروف العربية افتراضياً؛ للحفاظ عليها: جسون_تحويل(ق, ensure_ascii=خطأ)
  أو اكتب_ملف_جسون(ق, "ملف.json") للملفات)
- رياضيات: جذر(16)  مطلق(-5)  قوة(2, 8)  مقرب(3.7)

## المكتبات العربية
- توجد 96 مكتبة عربية جاهزة (math وos وrequests وflask وsqlite3 وغيرها).
- لا تخترع أسماء عربية من عندك: لكل مكتبة جدول «العربي ← Python» في ملف
  docs/<اسم>-library.md داخل المستودع. ابحث فيه قبل استعمال أي دالة غير
  المذكورة أعلاه، أو استعمل المكافئ العربي المؤكد فقط.
- المكتبات الخارجية (flask مثلاً) تحتاج تثبيت حزمة Python المقابلة.

## ممنوعات (أخطاء شائعة)
- لا تستعمل كلمات Python الإنجليزية (print, if, for, def, class) في ملف .apl.
- لا تنسَ «المتغير» عند أول تعريف.
- لا تفترض أن أي دالة Python لها مقابل عربي؛ تحقق من جداول التوثيق أولاً.
- مسارات الروابط في تطبيقات الويب اكتبها بأحرف لاتينية ("/health" لا "/صحة").
- أسماء الوسائط المفتاحية (keyword arguments) تبقى إنجليزية كما في Python:
  ensure_ascii, host, port, encoding وغيرها لا تُترجم.

## طريقة العمل المطلوبة منك
1. اكتب البرنامج كاملاً في ملف واحد أو عدة ملفات .apl.
2. بعد كل ملف، شغّل: python apl.py الملف.apl وأصلح أي خطأ عربي يظهر.
3. لا تعتبر البرنامج جاهزاً حتى يعمل فعلاً وتظهر النتيجة المتوقعة.
```

## كيف تستعمله

1. انسخ البرومبت كاملاً واستبدل `[اكتب هنا وصف برنامجك]` بوصف دقيق: ماذا يفعل البرنامج، ما مدخلاته، ما مخرجاته.
2. أعطِ الوكيل صلاحية تشغيل الأوامر (أو شغّل أنت بنفسك ما يعطيك إياه): القسم «طريقة العمل» يجبره على التشغيل والإصلاح بدل تسليم كود غير مجرب.
3. لو لم يكن المستودع أمام الوكيل، ألحق مع البرومبت ملف `docs/language-reference.md` وملف توثيق المكتبة التي يحتاجها مشروعك.

## كيف تراجع الناتج

- شغّل البرنامج بنفسك: `python apl.py البرنامج.apl`.
- فحص سريع بدون تشغيل: `apl check البرنامج.apl`.
- أي خطأ سيظهر بالعربية مع السطر؛ أرسله للوكيل كما هو وسيصلحه.

## لماذا هذا البرومبت مكتوب بهذه الطريقة

- «لا تخترع أسماء عربية»: أكثر أخطاء الوكلاء تخمين ترجمات غير موجودة؛ الجداول في `docs/` هي المرجع الوحيد.
- «شغّل وأصلح»: APL تعطي أخطاء عربية واضحة، فيكفي إرجاع الخطأ للوكيل ليصححه بنفسه.
- «ممنوعات»: جمعناها من أخطاء فعلية (نسيان `المتغير`، كلمات إنجليزية، مسارات عربية في الويب).
