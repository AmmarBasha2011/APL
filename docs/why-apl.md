# لماذا APL؟ — صفحة صادقة: أين تتفوق وأين تضعف

هذه الصفحة لا تبيعك اللغة. كل ادعاء هنا يمكنك التحقق منه في هذا المستودع، والعيوب مكتوبة بجانب المزايا.

## ما APL فعلاً

لغة برمجة عربية بالكامل — كلمات مفتاحية، أسماء، ورسائل أخطاء — تتحول إلى Python وتعمل على CPython. ليست لغة تعليمية مبسطة ولا محاكياً: برنامجك يستطيع استعمال قوة Python كلها.

## نقاط القوة (مع الدليل)

| الادعاء | الدليل |
|---------|--------|
| عربية بالكامل، حتى الأخطاء | شغّل أي خطأ وسترى رسالة عربية بموضع السطر؛ القائمة في [error-messages.md](error-messages.md) |
| كل قوة Python متاحة | الكود المولَّد Python عادي (`apl transpile`)؛ 74 مكتبة عربية بـ 278,065 عنصراً تغطي مكتبات Python القياسية والشائعة |
| بدون اعتماديات | `pyproject.toml` بلا dependencies؛ تحتاج Python 3.14+ فقط |
| أمثلة حقيقية مختبرة | 511 مثالاً في `examples/` يشغّلها CI في كل مرة (`test_examples.py`) |
| أداء مقاس لا مُدّعى | مقارنة مع Python في [قسم الأداء](../README.md) و`benchmarks/`؛ الترجمة أسرع 4.6× بالتحسينات الموثقة في [performance.md](performance.md) |
| تثبيت وأمر `apl`، مشاريع متعددة الملفات، استيراد بين ملفات `.apl` | [language-platform.md](language-platform.md) |
| دعم محرر VS Code (إكمال وتمييز) | مجلد `editors/` |
| ساحة معزولة اختيارية للكود غير الموثوق | مجلد `playground/` و`tests/test_sandbox.py` |

## نقاط الضعف (بنفس الصراحة)

- **النظام البيئي صغير جداً.** لن تجد إجابات Stack Overflow ولا مقالات ولا حزم طرف ثالث لـ APL. مرجعك الوحيد هو هذا المستودع.
- **مشرف واحد ولغة شابة.** استمرارية المشروع مرتبطة بشخص واحد، وواجهات اللغة قد تتغير.
- **الأداء = أداء CPython، لا أكثر.** APL لا تجعل برنامجك أسرع من Python، وتضيف كلفة ترجمة عند بدء التشغيل (تخفّها الذاكرة المؤقتة). للحوسبة الثقيلة ستعتمد على مكتبات Python الرقمية كما تفعل في Python.
- **ليست صندوق حماية.** تشغيل ملف `.apl` على جهازك مثل تشغيل Python بنفس الصلاحيات. لا تشغّل كوداً لا تثق به خارج `playground/`.
- **ترابط مع إصدارات مكتبات Python.** الترجمات العربية تغطي أسماء Python الحالية؛ عندما تحذف مكتبة خارجية أسماء في إصدار جديد، تحذف مقابلاتها هنا أيضاً (حدث فعلاً: 795 مفتاحاً أزيلت مع ترقيات الاعتماديات).
- **الأدوات محدودة.** لا مصحح أخطاء خاص، لا مدير حزم، دعم المحررات يقتصر على VS Code، ويتطلب Python 3.14+ وهو إصدار حديث جداً قد لا يكون على خادمك بعد.
- **التوثيق عربي فقط تقريباً.** ميزة لجمهوره، وعائق لغيره.

## متى تختارها

- تعليم البرمجة بالعربية: مفاهيم وأخطاء بلغة المتعلم، دون حاجز لغوي مزدوج.
- فرق أو أفراد عرب يفضلون قراءة وكتابة الكود بلغتهم، ويريدون قوة Python الحقيقية لا لعبة تعليمية.
- أدوات داخلية وسكربتات ونماذج أولية حيث وضوح الكود للناطقين بالعربية أهم من النظام البيئي.

## متى لا تختارها

- نظام إنتاجي يحتاج نظاماً بيئياً ناضجاً ومجتمعاً يجيب عن أسئلتك.
- فريق يقرأ الإنجليزية بلا صعوبة — Python مباشرة تعطيه نفس القوة بنظام بيئي أكبر.
- أداء يتجاوز قدرة CPython، أو اعتماد على أدوات تطوير متقدمة (تنقيب، تحليل ثابت، مدير حزم).

## الخلاصة بجملة

APL تزيل حاجز اللغة الإنجليزية عن قوة Python الكاملة، وتدفع ثمن ذلك صغر نظامها البيئي وحداثة عمرها. اخترها عندما يكون الحاجز هو مشكلتك الحقيقية.
