# مكتبة تعدد المهام — `threading`

مكتبة threading الكاملة بالعربي، تعدد المهام:

## إنشاء ثريد

| العربي | Python | الوصف |
|--------|--------|-------|
| `ثريد(هدف=دالة)` | `threading.Thread(هدف=دالة)` | إنشاء ثريد |
| `أنشئ_ثريد(هدف=دالة)` | `threading.Thread(هدف=دالة)` | إنشاء ثريد |
| `مهمة_خيوط(هدف=دالة)` | `threading.Thread(هدف=دالة)` | إنشاء مهمة |
| `أنشئ_مهمة_خيوط(هدف=دالة)` | `threading.Thread(هدف=دالة)` | إنشاء مهمة |
| `عامل(هدف=دالة)` | `threading.Thread(هدف=دالة)` | إنشاء عامل |

## التحكم في الثريد

| العربي | Python | الوصف |
|--------|--------|-------|
| `ابدأ_خيوط()` | `thread.start()` | بدء الثريد |
| `انتظر_خيوط()` | `thread.join()` | انتظار انتهاء الثريد |
| `ألغى_خيوط()` | `thread.cancel()` | إلغاء الثريد |

## حالة الثريد

| العربي | Python | الوصف |
|--------|--------|-------|
| `نشط()` | `thread.is_alive()` | هل الثريد نشط |
| `اسم()` | `thread.name` | اسم الثريد |
| `دايمون()` | `thread.daemon` | هل الثريد دايمون |

## القفل (Lock)

| العربي | Python | الوصف |
|--------|--------|-------|
| `قفل_خيوط()` | `threading.Lock()` | إنشاء قفل |
| `أنشئ_قفل()` | `threading.Lock()` | إنشاء قفل |
| `امتلك_خيوط()` | `lock.acquire()` | امتلاك القفل |
| `أطلق_خيوط()` | `lock.release()` | إطلاق القفل |

## الإشارة (Semaphore)

| العربي | Python | الوصف |
|--------|--------|-------|
| `إشارة_خيوط()` | `threading.Semaphore()` | إنشاء إشارة |
| `أنشئ_إشارة()` | `threading.Semaphore()` | إنشاء إشارة |

## الأحداث (Event)

| العربي | Python | الوصف |
|--------|--------|-------|
| `حدث_خيوط()` | `threading.Event()` | إنشاء حدث |
| `أنشئ_حدث()` | `threading.Event()` | إنشاء حدث |
| `انتظر_حدث_خيوط()` | `event.wait()` | انتظار الحدث |
| `أطلق_حدث_خيوط()` | `event.set()` | إطلاق الحدث |
| `امسح_حدث_خيوط()` | `event.clear()` | مسح الحدث |

## المؤقت (Timer)

| العربي | Python | الوصف |
|--------|--------|-------|
| `مؤقت_خيوط(ثوان, دالة)` | `threading.Timer(ثوان, دالة)` | مؤقت |
| `أنشئ_مؤقت_خيوط(ثوان, دالة)` | `threading.Timer(ثوان, دالة)` | إنشاء مؤقت |

## الثريد الحالي

| العربي | Python | الوصف |
|--------|--------|-------|
| `ثريد_حالي()` | `threading.current_thread()` | الثريد الحالي |
| `الثريد_الحالي()` | `threading.current_thread()` | الثريد الحالي |
| `عداد_ثريدات()` | `threading.active_count()` | عداد الثريدات |
| `نوم_خيوط(ثوان)` | `time.sleep(ثوان)` | نوم لثواني |

## مثال

```apl
دالة_عمل(اسم):
    اطبع "بدء العمل:", اسم
    نوم_خيوط(0.1)
    اطبع "انتهاء العمل:", اسم

المتغير ت1 = ثريد(target=دالة_عمل, args=("أولى",))
المتغير ت2 = ثريد(target=دالة_عمل, args=("ثانية",))

ت1.start()
ت2.start()

ت1.join()
ت2.join()

اطبع "انتهت كل المهام"
```
