# مكتبة تعدد المهام — `threading`

مكتبة threading الكاملة بالعربي، تعدد المهام:

## إنشاء ثريد

| العربي | Python | الوصف |
|--------|--------|-------|
| `ثريد(هدف=دالة)` | `threading.Thread(هدف=دالة)` | إنشاء ثريد |
| `أنشئ_ثريد(هدف=دالة)` | `threading.Thread(هدف=دالة)` | إنشاء ثريد |
| `مهمة(هدف=دالة)` | `threading.Thread(هدف=دالة)` | إنشاء مهمة |
| `أنشئ_مهمة(هدف=دالة)` | `threading.Thread(هدف=دالة)` | إنشاء مهمة |
| `عامل(هدف=دالة)` | `threading.Thread(هدف=دالة)` | إنشاء عامل |

## التحكم في الثريد

| العربي | Python | الوصف |
|--------|--------|-------|
| `ابدأ()` | `thread.start()` | بدء الثريد |
| `انتظر()` | `thread.join()` | انتظار انتهاء الثريد |
| `ألغى()` | `thread.cancel()` | إلغاء الثريد |

## حالة الثريد

| العربي | Python | الوصف |
|--------|--------|-------|
| `نشط()` | `thread.is_alive()` | هل الثريد نشط |
| `اسم()` | `thread.name` | اسم الثريد |
| `دايمون()` | `thread.daemon` | هل الثريد دايمون |

## القفل (Lock)

| العربي | Python | الوصف |
|--------|--------|-------|
| `قفل()` | `threading.Lock()` | إنشاء قفل |
| `أنشئ_قفل()` | `threading.Lock()` | إنشاء قفل |
| `امتلك()` | `lock.acquire()` | امتلاك القفل |
| `أطلق()` | `lock.release()` | إطلاق القفل |

## الإشارة (Semaphore)

| العربي | Python | الوصف |
|--------|--------|-------|
| `إشارة()` | `threading.Semaphore()` | إنشاء إشارة |
| `أنشئ_إشارة()` | `threading.Semaphore()` | إنشاء إشارة |

## الأحداث (Event)

| العربي | Python | الوصف |
|--------|--------|-------|
| `حدث()` | `threading.Event()` | إنشاء حدث |
| `أنشئ_حدث()` | `threading.Event()` | إنشاء حدث |
| `انتظر_حدث()` | `event.wait()` | انتظار الحدث |
| `أطلق_حدث()` | `event.set()` | إطلاق الحدث |
| `امسح_حدث()` | `event.clear()` | مسح الحدث |

## المؤقت (Timer)

| العربي | Python | الوصف |
|--------|--------|-------|
| `مؤقت(ثوان, دالة)` | `threading.Timer(ثوان, دالة)` | مؤقت |
| `أنشئ_مؤقت(ثوان, دالة)` | `threading.Timer(ثوان, دالة)` | إنشاء مؤقت |

## الثريد الحالي

| العربي | Python | الوصف |
|--------|--------|-------|
| `ثريد_حالي()` | `threading.current_thread()` | الثريد الحالي |
| `الثريد_الحالي()` | `threading.current_thread()` | الثريد الحالي |
| `عداد_ثريدات()` | `threading.active_count()` | عداد الثريدات |
| `نوم(ثوان)` | `time.sleep(ثوان)` | نوم لثواني |

## مثال

```apl
دالة عمل(اسم):
    اطبع "بدء العمل:", اسم
    نوم(2)
    اطبع "انتهاء العمل:", اسم

المتغير t1 = ثريد(هدف=عمل, args=("أولى",))
المتغير t2 = ثريد(هدف=عمل, args=("ثانية",))

t1.ابدأ()
t2.ابدأ()

t1.انتظر()
t2.انتظر()

اطبع "انتهت كل المهام"
```
