# مكتبة التسجيل — `logging`

مكتبة logging الكاملة بالعربي، تسجيل الأحداث:

## الإنشاء والتكوين

| العربي | Python | الوصف |
|--------|--------|-------|
| `سجل(اسم)` | `logging.getLogger(اسم)` | إنشاء مسجل |
| `أنشئ_مسجل(اسم)` | `logging.getLogger(اسم)` | إنشاء مسجل |
| `مسجل(اسم)` | `logging.getLogger(اسم)` | مسجل (مختصر) |
| `جذر()` | `logging.root` | المسجل الجذر |
| `تكوين()` | `logging.basicConfig()` | تكوين أساسي |

## المستويات

| العربي | Python |
|--------|--------|
| `مستوى_تصحيح()` | DEBUG |
| `مستوى_معلومات()` | INFO |
| `مستوى_تحذير()` | WARNING |
| `مستوى_خطأ()` | ERROR |
| `level_حرج()` | CRITICAL |

## المعالجات

| العربي | Python |
|--------|--------|
| `معالج_ملف(ملف)` | FileHandler |
| `معالج_شاشة()` | StreamHandler |
| `أضف_معالج(معالج)` | addHandler |
| `أزل_معالج(معالج)` | removeHandler |

## التنسيق

| العربي | Python |
|--------|--------|
| `شكل(تنسيق)` | Formatter |
| `ضع_شكل(شكل)` | setFormatter |
| `أضف_فلتر(فلتر)` | addFilter |

## التسجيل

| العربي | Python |
|--------|--------|
| `تصحيح(رسالة)` | debug |
| `معلومات(رسالة)` | info |
| `تحذير(رسالة)` | warning |
| `خطأ(رسالة)` | error |
| `حرج(رسالة)` | critical |
| `استثناء(رسالة)` | exception |

## مثال

```apl
# تكوين المسجل
تكوين(مستوى=مستوى_معلومات)

# إنشاء مسجل
المتغير logger = جل_("تطبيقي")

# تسجيل معلومات
معلومات("بدء التطبيق")

# تسجيل تحذير
تحذير("هذا تحذير")

# تسجيل خطأ
خطأ("حدث خطأ")

# تسجيل استثناء
try:
    raise ValueError("خطأ")
except:
   استثناء("فشل")
```
