# مكتبة التسجيل — `logging`

مكتبة logging الكاملة بالعربي، تسجيل الأحداث:

## الإنشاء والتكوين

| العربي | Python | الوصف |
|--------|--------|-------|
| `مسجّل(اسم)` | `logging.getLogger(اسم)` | إنشاء مسجل |
| `أنشئ_مسجل(اسم)` | `logging.getLogger(اسم)` | إنشاء مسجل |
| `مسجل(اسم)` | `logging.getLogger(اسم)` | مسجل (مختصر) |
| `جذر_تسجيل()` | `logging.root` | المسجل الجذر |
| `تكوين_تسجيل()` | `logging.basicConfig()` | تكوين أساسي |

## المستويات

| العربي | Python |
|--------|--------|
| `مستوى_تصحيح()` | DEBUG |
| `مستوى_معلومات()` | INFO |
| `مستوى_تحذير()` | WARNING |
| `مستوى_خطأ()` | ERROR |
| `level_حرج()` | CRITICAL |

## المعالجات

| العربي | Python |
|--------|--------|
| `معالج_ملف(ملف)` | FileHandler |
| `معالج_شاشة()` | StreamHandler |
| `أضف_معالج(معالج)` | addHandler |
| `أزل_معالج(معالج)` | removeHandler |

## التنسيق

| العربي | Python |
|--------|--------|
| `شكل(تنسيق)` | Formatter |
| `ضع_شكل(شكل)` | setFormatter |
| `أضف_فلتر(فلتر)` | addFilter |

## التسجيل

| العربي | Python |
|--------|--------|
| `تصحيح(رسالة)` | debug |
| `معلومات(رسالة)` | info |
| `تحذير(رسالة)` | warning |
| `خطأ_تسجيل(رسالة)` | error |
| `حرج(رسالة)` | critical |
| `استثناء_تسجيل(رسالة)` | exception |

## مثال

```apl
تكوين_تسجيل(level=مستوى_معلومات)
المتغير مسجل_التطبيق = مسجّل("تطبيقي")
اطبع_معلومات("بدء التطبيق")
اطبع_خطأ("حدث خطأ")
حاول:
    raise ValueError("س")
إمسك:
    اطبع_تحذير("تم التقاط الخطأ")
```
