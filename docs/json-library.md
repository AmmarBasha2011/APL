# مكتبة JSON — `json`

مكتبة JSON بالعربي، متوافقة مع Python json:

## مختصرات (Shortcuts)

| العربي | Python | الوصف |
|--------|--------|-------|
| `جسون(نص)` | `json.loads(نص)` | قراءة JSON من نص (مختصر) |
| `جسون_تحويل(بيانات)` | `json.dumps(بيانات)` | كتابة JSON لنص (مختصر) |

## كتابة (Writing)

| العربي | Python | الوصف |
|--------|--------|-------|
| `اكتب_جسون(بيانات)` | `json.dumps(بيانات)` | كتابة JSON لنص |
| `ل_جسون(بيانات)` | `json.dumps(بيانات)` | كتابة JSON لنص |

## قراءة (Reading)

| العربي | Python | الوصف |
|--------|--------|-------|
| `اقرأ_جسون(نص)` | `json.loads(نص)` | قراءة JSON من نص |
| `من_جسون(نص)` | `json.loads(نص)` | قراءة JSON من نص |

## ملفات (Files)

| العربي | Python | الوصف |
|--------|--------|-------|
| `من_ملف_جسون(ملف)` | `json.load(ملف)` | قراءة من ملف JSON |
| `لملف_جسون(بيانات, ملف)` | `json.dump(بيانات, ملف)` | كتابة لملف JSON |

## مثال

```apl
# Write JSON
المتغير بيانات = قاموس()
بيانات["name"] = "عمار"
بيانات["age"] = 25
المتغير نص = اكتب_جسون(بيانات)
print("اكتب_جسون:", نص)

# Read JSON
المتغير من_نص = من_جسون(نص)
print("من_جسون:", من_نص)
print("name:", من_نص["name"])

# Short forms
print("جسون:", جسون('{"x": 1}'))
print("جسون_تحويل:", جسون_تحويل({"y": 2}))
```
