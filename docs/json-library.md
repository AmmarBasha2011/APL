# مكتبة JSON — `json`

مكتبة JSON بالعربي، متوافقة مع Python json:

**5 عنصراً عربياً** (الدوال: 10).

## الدوال (5)

| العربي | Python |
|--------|--------|
| `جسون` | `json.loads` |
| `جسون_تحويل` | `json.dumps` |
| `لملف_جسون` | `json.dump` |
| `اقرأ_ملف_جسون` | `_apl_json_load_file` |
| `اكتب_ملف_جسون` | `_apl_json_dump_file` |

## مثال

```apl
# Write JSON
المتغير بيانات = قاموس()
بيانات["name"] = "عمار"
بيانات["age"] = 25
المتغير نص = اكتب_جسون(بيانات)
print("اكتب_جسون:", نص)

# Read JSON
المتغير من_نص = من_جسون(نص)
print("من_جسون:", من_نص)
print("name:", من_نص["name"])

# Short forms
print("جسون:", جسون('{"x": 1}'))
print("جسون_تحويل:", جسون_تحويل({"y": 2}))
```
