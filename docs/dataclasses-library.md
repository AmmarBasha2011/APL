# مكتبة فئات البيانات والتعدادات — `dataclasses` & `enum`

مكتبة dataclasses و enum و abc الكاملة بالعربي:

## Dataclasses

| العربي | Python | الوصف |
|--------|--------|-------|
| `@dataclass` | `@dataclass` | مُزيِّن فئة البيانات |
| `@فئة_بيانات` | `@dataclass` | مُزيِّن (عربي) |
| `حقول(فئة)` | `dataclasses.fields(فئة)` | حقول الفئة |
| `حقل(افتراضي, مقارنة)` | `dataclasses.field(...)` | حقل مخصص |
| `تهيئة_بعد(ذات)` | `__post_init__` | بعد التهيئة |
| `تحويل_لصف(كائن)` | `dataclasses.astuple` | تحويل لصف |
| `تحويل_لقاموس(كائن)` | `dataclasses.asdict` | تحويل لقاموس |
| `استبدال(كائن, **تغييرات)` | `dataclasses.replace` | استبدال قيم |
| `فحص_فئة_بيانات(كائن)` | `dataclasses.is_dataclass` | هل فئة بيانات |

## مثال Dataclass

```apl
@dataclass
class مستخدم:
    اسم: نص
    عمر: عدد_صحيح
    بريد: نص = ""

    def تهيئة_بعد(ذات):
        if ذات.عمر < 0:
            raise ValueError("العمر لا يمكن أن يكون سالب")

# إنشاء كائن
المتغير u = dataclass.مستخدم("عمار", 25, "amar@email.com")
اطبع u.اسم, u.عمر

# تحويل لقاموس
المتغير d = تحويل_لقاموس(u)
اطبع d

# استبدال قيم
المتغير u2 = استبدال(u, عمر=26)
اطبع u2.عمر
```

## مثال Enum

```apl
@enum.unique
class لون(enum.Enum):
    أحمر = 1
    أخضر = 2
    أزرق = 3

# الوصول للقيمة
اطبع لون.أحمر
اطبع لون.أحمر.اسم
اطبع لون.أحمر.قيمة

# التحقق
if لون.أحمر == لون.أخضر:
   اطبع "نفس اللون"
else:
   اطعون "ألوان مختلفة"

# تعداد مع قيم تلقائية
class حجم(enum.Enum):
    صغير = enum.auto()
    متوسط = enum.auto()
    كبير = enum.auto()
```

## مثال ABC

```apl
@dataclass
class شكل(abc.ABC):
    abc.abstractmethod
    def مساحة(ذات):
        pass

    abc.abstractmethod
    def محيط(ذات):
        pass

@dataclass
class مستطيل(شكل):
    عرض: عدد_صحيح
    ارتفاع: عدد_صحيح

    def مساحة(ذات):
        return ذات.عرض * ذات.ارتفاع

    def محيط(ذات):
        return 2 * (ذات.عرض + ذات.ارتفاع)
```
