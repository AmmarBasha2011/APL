# مكتبة قواعد البيانات — `sqlite3`

مكتبة SQLite3 الكاملة بالعربي، قاعدة بيانات محلية:

## الاتصال بقاعدة البيانات

| العربي | Python | الوصف |
|--------|--------|-------|
| `افتح_قاعدة('ملف.db')` | `sqlite3.connect('ملف.db')` | فتح قاعدة بيانات |
| `افتح_قاعدة_بيانات('ملف.db')` | `sqlite3.connect('ملف.db')` | فتح قاعدة بيانات |
| `اتصل_قاعدة('ملف.db')` | `sqlite3.connect('ملف.db')` | اتصال بقاعدة |
| `قاعدة('ملف.db')` | `sqlite3.connect('ملف.db')` | اتصال (مختصر) |

## المؤشر (Cursor)

| العربي | Python | الوصف |
|--------|--------|-------|
| `مؤشر()` | `cursor` | إنشاء مؤشر |
| `أنشئ_مؤشر()` | `connection.cursor()` | إنشاء مؤشر |

## تنفيذ الاستعلامات

| العربي | Python | الوصف |
|--------|--------|-------|
| `نفذ('استعلام')` | `cursor.execute('استعلام')` | تنفيذ استعلام |
| `نفذ_استعلام('استعلام')` | `cursor.execute('استعلام')` | تنفيذ استعلام |
| `نفذ_كثير('استعلام', بيانات)` | `cursor.executemany('استعلام', بيانات)` | تنفيذ كثير |
| `نفذ_سكريبت('سكريبت')` | `cursor.executescript('سكريبت')` | تنفيذ سكريبت |

## جلب النتائج

| العربي | Python | الوصف |
|--------|--------|-------|
| `جلب_واحد()` | `cursor.fetchone()` | جلب صف واحد |
| `جلب_الكل()` | `cursor.fetchall()` | جلب كل الصفوف |
| `جلب_عدد(ن)` | `cursor.fetchmany(ن)` | جلب ن صفوف |

## التأكيد والتراجع

| العربي | Python | الوصف |
|--------|--------|-------|
| `تأكد()` | `connection.commit()` | تأكيد التغييرات |
| `احفظ()` | `connection.commit()` | حفظ التغييرات |
| `تراجع()` | `connection.rollback()` | تراجع عن التغييرات |

## الإغلاق

| العربي | Python | الوصف |
|--------|--------|-------|
| `أغلق()` | `connection.close()` | إغلاق الاتصال |
| `أغلق_قاعدة()` | `connection.close()` | إغلاق قاعدة البيانات |

## خصائص الاتصال

| العربي | Python | الوصف |
|--------|--------|-------|
| `صف_مصنع` | `connection.row_factory` | مصنع الصفوف |
| `نص_مصنع` | `connection.text_factory` | مصنع النصوص |
| `عزل_مستوى` | `connection.isolation_level` | مستوى العزل |

## مثال كامل

```apl
# إنشاء قاعدة بيانات
المتغير conn = افتح_قاعدة('test.db')
المتغير c = مؤشر()

# إنشاء جدول
نفذ('CREATE TABLE IF NOT EXISTS users (id INTEGER PRIMARY KEY, name TEXT, age INTEGER)')

# إدراج بيانات
نفذ('INSERT INTO users (name, age) VALUES (?, ?)', ('عمار', 25))
نفذ('INSERT INTO users (name, age) VALUES (?, ?)', ('محمد', 30))

# تأكيد
تأكد()

# استعلام
نفذ('SELECT * FROM users')
المتغير rows = جلب_الكل()
اطبع rows

# إغلاق
أغلق()
```
