# مكتبة الرياضيات — `math`

كل الدوال والثوابت من مكتبة `math` في Python، مترجمة بالكامل:

## مثلثات (Trigonometry)

| العربي | Python | الوصف |
|--------|--------|-------|
| `جتا(x)` | `math.cos(x)` | جيب التمام |
| `جب(x)` | `math.sin(x)` | الجيب |
| `ظا(x)` | `math.tan(x)` | الظل |
| `م_جتا(x)` | `math.acos(x)` | قوس جيب التمام |
| `م_جب(x)` | `math.asin(x)` | قوس الجيب |
| `م_ظا(x)` | `math.atan(x)` | قوس الظل |
| `م_ظا2(y, x)` | `math.atan2(y, x)` | قوس الظل بمركبتين |

## دوال زائدية (Hyperbolic)

| العربي | Python | الوصف |
|--------|--------|-------|
| `جتا_زائدي(x)` | `math.cosh(x)` | جيب التمام الزائدي |
| `جب_زائدي(x)` | `math.sinh(x)` | الجيب الزائدي |
| `ظا_زائدي(x)` | `math.tanh(x)` | الظل الزائدي |
| `م_جتا_زائدي(x)` | `math.acosh(x)` | قوس جتا زائدي |
| `م_جب_زائدي(x)` | `math.asinh(x)` | قوس جب زائدي |
| `م_ظا_زائدي(x)` | `math.atanh(x)` | قوس ظا زائدي |

## لوغاريتمات وأس (Logarithms & Exponentials)

| العربي | Python | الوصف |
|--------|--------|-------|
| `لوغاريتم(x, base)` | `math.log(x, base)` | لوغاريتم (اختياري الأساس) |
| `لوغاريتم_2(x)` | `math.log2(x)` | لوغاريتم للأساس 2 |
| `لوغاريتم_10(x)` | `math.log10(x)` | لوغاريتم للأساس 10 |
| `لوغاريتم_زائد_واحد(x)` | `math.log1p(x)` | log(1 + x) |
| `أس(x)` | `math.exp(x)` | e^x |
| `أس_ناقص_واحد(x)` | `math.expm1(x)` | e^x - 1 |

## قوة وجذور (Powers & Roots)

| العربي | Python | الوصف |
|--------|--------|-------|
| `جذر(x)` | `math.sqrt(x)` | الجذر التربيعي |
| `جذر_صحيح(x)` | `math.isqrt(x)` | الجذر التربيعي الصحيح |
| `قوة(base, exp)` | `pow(base, exp)` | الأس |

## تقريب (Rounding)

| العربي | Python | الوصف |
|--------|--------|-------|
| `سقف(x)` | `math.ceil(x)` | سقف (أصغر صحيح ≥ x) |
| `أرضي(x)` | `math.floor(x)` | أرضي (أكبر صحيح ≤ x) |
| `اقتطاع(x)` | `math.trunc(x)` | اقتطاع الكسر |
| `مقرب(x)` | `round(x)` | تقريب عادي |

## نظرية الأعداد (Number Theory)

| العربي | Python | الوصف |
|--------|--------|-------|
| `مضروب(n)` | `math.factorial(n)` | المضروب n! |
| `توافيق(n, k)` | `math.comb(n, k)` | عدد التوافيق |
| `تباديل(n, k)` | `math.perm(n, k)` | عدد التباديل |
| `قاسم_مشترك(a, b)` | `math.gcd(a, b)` | القاسم المشترك الأكبر |
| `مضاعف_مشترك(a, b)` | `math.lcm(a, b)` | المضاعف المشترك الأصغر |
| `جداء(iterable)` | `math.prod(iterable)` | جداء عناصر |

## عوائم (Floating-Point)

| العربي | Python | الوصف |
|--------|--------|-------|
| `مطلق_عشري(x)` | `math.fabs(x)` | القيمة المطلقة (عشري) |
| `باقي_قسمة(x, y)` | `math.fmod(x, y)` | باقي القسمة |
| `كسر_صحيح(x)` | `math.modf(x)` | (كسر, صحيح) |
| `تفكيك(x)` | `math.frexp(x)` | (مانتيسا, أس) |
| `ضرب_أس(x, i)` | `math.ldexp(x, i)` | x * 2^i |
| `نسخ_الإشارة(x, y)` | `math.copysign(x, y)` | \|x\| بإشارة y |
| `التالي(x, y)` | `math.nextafter(x, y)` | أقرب عشري باتجاه y |
| `وحدة_الدقة(x)` | `math.ulp(x)` | أصغر وحدة دقة |
| `مجموع_دقيق(iter)` | `math.fsum(iter)` | جمع دقيق |
| `باقي(x, y)` | `math.remainder(x, y)` | الباقي حسب IEEE |

## مقارنة (Comparison / Classification)

| العربي | Python | الوصف |
|--------|--------|-------|
| `قريب_من(a, b)` | `math.isclose(a, b)` | a ≈ b |
| `محدود(x)` | `math.isfinite(x)` | x محدود |
| `لا_نهائي(x)` | `math.isinf(x)` | x لا نهائي |
| `ليس_رقم(x)` | `math.isnan(x)` | x = NaN |

## هندسة (Geometry)

| العربي | Python | الوصف |
|--------|--------|-------|
| `مسافة(p, q)` | `math.dist(p, q)` | المسافة الإقليدية |
| `وتر(*coordinates)` | `math.hypot(*coordinates)` | الوتر (الجذر التربيعي للمجموع) |

## تحويل زوايا (Angle Conversion)

| العربي | Python | الوصف |
|--------|--------|-------|
| `درجات(rad)` | `math.degrees(rad)` | راديان → درجات |
| `راديان(deg)` | `math.radians(deg)` | درجات → راديان |

## دوال خاصة (Special Functions)

| العربي | Python | الوصف |
|--------|--------|-------|
| `دالة_الخطأ(x)` | `math.erf(x)` | دالة الخطأ |
| `دالة_الخطأ_المكملة(x)` | `math.erfc(x)` | المكملة |
| `جاما(x)` | `math.gamma(x)` | دالة جاما |
| `لوغاريتم_جاما(x)` | `math.lgamma(x)` | log Γ(x) |

## ثوابت رياضية (Mathematical Constants)

| العربي | Python | القيمة |
|--------|--------|--------|
| `ط` | `math.pi` | 3.141592653589793 |
| `ه` | `math.e` | 2.718281828459045 |
| `تاو` | `math.tau` | 6.283185307179586 |
| `لانهائي_موجب` | `math.inf` | ∞ |

## مثال

```apl
المتغير زاوية = راديان(45)
اطبع "الجيب:", جب(زاوية)
اطبع "جيب التمام:", جتا(زاوية)
اطبع "ط:", ط
اطبع "5! =", مضروب(5)
اطبع "توافيق(5,2) =", توافيق(5, 2)
```
