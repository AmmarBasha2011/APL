# مكتبة المناطق الزمنية — `zoneinfo`

التعامل مع المناطق الزمنية worldwide حسب معيار IANA.

**8 عنصر** (5 دالة، 1 خاصية، 2 ثابت).

## الدوال

| العربي | Python | الوصف |
|--------|--------|-------|
| `منطقة_زمنية(...)` | `zoneinfo.ZoneInfo` | كائن منطقة زمنية |
| `كل_المناطق_الزمنية(...)` | `zoneinfo.available_timezones` | كل المناطق المتاحة |
| `من_النص_إلى_منطقة(...)` | `_apl_zone_from_key` | من نص إلى منطقة |
| `إعادة_ضبط_مسار_المناطق(...)` | `zoneinfo.reset_tzpath` | إعادة تعيين مسار البحث |
| `منطقة_من_النص(...)` | `zoneinfo.ZoneInfo` | نص -> ZoneInfo |

## خصائص الكائن (Properties)

تُستخدم بعد النقطة: `كسر.بسط_كسر`

| العربي | Python | الوصف |
|--------|--------|-------|
| `مفتاح_المنطقة` | `.key` |  |

## الثوابت (Constants)

تُستخدم **بدون** أقواس.

| العربي | Python | الوصف |
|--------|--------|-------|
| `مسار_المناطق` | `zoneinfo.TZPATH` |  |
| `منطقة_utc` | `datetime.timezone.utc` |  |

## أمثلة

```apl
المتغير القاهرة = منطقة_زمنية("Africa/Cairo")
اطبع "اسم المنطقة:", القاهرة.مفتاح_المنطقة
اطبع "الرياض:", منطقة_من_النص("Asia/Riyadh").مفتاح_المنطقة
اطبع "عدد المناطق المتاحة:", طول(كل_المناطق_الزمنية()) > 100
```
