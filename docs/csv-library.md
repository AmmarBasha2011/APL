# مكتبة ملفات CSV — `csv`

مكتبة CSV الكاملة بالعربي، قراءة وكتابة ملفات البيانات:

## القراءة

| العربي | Python | الوصف |
|--------|--------|-------|
| `اقرأ_csv(ملف)` | `csv.reader(ملف)` | قراءة ملف CSV |
| `اقرأ_قاموس(ملف)` | `csv.DictReader(ملف)` | قراءة كقاموس |
| `اقرأ_ملف_csv(اسم)` | `open(اسم, 'r')` | فتح ملف CSV للقراءة |

## الكتابة

| العربي | Python | الوصف |
|--------|--------|-------|
| `اكتب_csv(ملف)` | `csv.writer(ملف)` | كتابة ملف CSV |
| `اكتب_قاموس(ملف, حقول)` | `csv.DictWriter(ملف, حقول)` | كتابة قاموس |
| `اكتب_ملف_csv(اسم)` | `open(اسم, 'w')` | فتح ملف CSV للكتابة |

## الخصائص

| العربي | Python | الوصف |
|--------|--------|-------|
| `فاصل` | `delimiter` | الفاصل (عادةً , أو ;) |
| `اقتباس` | `quotechar` | حرف الاقتباس |
| `هروب` | `escapechar` | حرف الهروب |
| `سطر_جديد` | `lineterminator` | محدد السطر الجديد |
| `اقتباس_نمط` | `quoting` | نمط الاقتباس |
| `تخطي_مسافات` | `skipinitialspace` | تخطي المسافات الأولية |
| `صارم` | `strict` | وضع صارم |

## مثال

```apl
# كتابة ملف CSV
المتغير f = اكتب_ملف_csv('data.csv')
المتغير writer = اكتب_csv(f)
writer.writerow(['الاسم', 'العمر', 'المدينة'])
writer.writerow(['عمار', '25', 'القاهرة'])
writer.writerow(['محمد', '30', 'الرياض'])
f.close()

# قراءة ملف CSV
المتغير f2 = اقرأ_ملف_csv('data.csv')
المتغير reader = اقرأ_csv(f2)
لكل row في reader:
   اطبع row
f2.close()

# قراءة كقاموس
المتغير f3 = اقرأ_ملف_csv('data.csv')
المتغير dict_reader = اقرأ_قاموس(f3)
لكل row في dict_reader:
   اطبع row['الاسم'], row['العمر']
f3.close()
```
