# مكتبة البرمجة غير المتزامنة — `asyncio`

مكتبة asyncio الكاملة بالعربي، برمجة غير متزامنة:

## الدوال الأساسية

| العربي | Python | الوصف |
|--------|--------|-------|
| `شغل(دالة)` | `asyncio.run(دالة)` | تشغيل دالة غير متزامنة |
| `أنشئ_مهمة(دالة)` | `asyncio.create_task(دالة)` | إنشاء مهمة |
| `انتظر(مهمة)` | `asyncio.wait(مهمة)` | انتظار مهمة |
| `انتظر_أي(مهمة, مهلة)` | `asyncio.wait_for(مهمة, مهلة)` | انتظار مع مهلة |
| `اجمع(مهام)` | `asyncio.gather(مهام)` | جمع مهام |
| `نوم(ثوان)` | `asyncio.sleep(ثوان)` | نوم لثواني |
| `حلقة()` | `asyncio.get_event_loop()` | الحصول على الحلقة |
| `حلقة_جديدة()` | `asyncio.new_event_loop()` | إنشاء حلقة جديدة |
| `اجعل_حلقة(حلقة)` | `asyncio.set_event_loop(حلقة)` | تعيين الحلقة |

|--------|--------|-------|

| `ألغى_مهمة(مهمة)` | `مهمة.cancel()` | إلغاء مهمة |
| `حالة_مهمة(مهمة)` | `مهمة.done()` | حالة المهمة |
| `نتيجة_مهمة(مهمة)` | `مهمة.result()` | نتيجة المهمة |
| `استثناء_مهمة(مهمة)` | `مهمة.exception()` | استثناء المهمة |
| `أضف_استدعاء(مهمة, دالة)` | `مهمة.add_done_callback(دالة)` | إضافة استدعاء |
| `اسم_مهمة(مهمة)` | `مهمة.get_name()` | اسم المهمة |
| `ضع_اسم(مهمة, اسم)` | `مهمة.set_name(اسم)` | تعيين اسم |

    return {"url": url, "status": "ok"}

# تشغيل الدالة
شغل(رابط_ويب("https://example.com"))

# جمع مهام
async def رئيسي():
