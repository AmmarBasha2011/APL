# مكتبة تحليل الوسائط — `argparse`

مكتبة argparse الكاملة بالعربي، تحليل وسائط سطر الأوامر:

## الإنشاء

| العربي | Python | الوصف |
|--------|--------|-------|
| `أنشئ_محلل()` | `argparse.ArgumentParser()` | إنشاء محلل |
| `محلل()` | `argparse.ArgumentParser()` | محلل (مختصر) |
| `محلل_وسائط()` | `argparse.ArgumentParser()` | محلل وسائط |

## الخصائص

| العربي | Python |
|--------|--------|
| `وصف(نص)` | description |
| `تلميح_استخدام(نص)` | usage |
| `خاتمة_مساعدة(نص)` | epilog |

## المجموعات

| العربي | Python |
|--------|--------|
| `أضف_مجموعة(عنوان)` | add_argument_group |
| `مجموعة_متنافية()` | add_mutually_exclusive_group |

## الحجج

| العربي | Python |
|--------|--------|
| `أضف_حجة(اسم)` | add_argument |
| `حجة(اسم)` | add_argument |
| `أضف_خيار(اسم)` | add_argument |
| `خيار(اسم)` | add_argument |

## خصائص الحجة

| العربي | Python |
|--------|--------|
| `وجهة(اسم)` | dest |
| `نوع(نوع)` | type |
| `افتراضي(قيمة)` | default |
| `مطلوب(صحيح)` | required |
| `تلميح(نص)` | help |
| `الإجراء(فعل)` | action |
| `خيارات_وسائط(قائمة)` | choices |

## الإجراءات

| العربي | Python |
|--------|--------|
| `خزن(قيمة)` | store |
| `خزن_ثابت(قيمة)` | store_const |
| `خزن_صحيح()` | store_true |
| `خزن_خطأ()` | store_false |
| `أضف_قيمة(قيمة)` | append |
| `عد_مرات()` | count |
| `مساعدة_وسائط()` | help |
| `إصدار_وسائط(نص)` | version |

## التحليل

| العربي | Python |
|--------|--------|
| `حلل()` | parse_args |
| `حلل_وسائط()` | parse_args |
| `حلل_معروف()` | parse_known_args |

## الرسائل

| العربي | Python |
|--------|--------|
| `خطأ_وسائط(رسالة)` | error |
| `خروج(حالة)` | exit |
| `اطبع_مساعدة()` | print_help |
| `اطبع_استخدام()` | print_usage |

## مثال

```apl
# إنشاء محلل
المتغير parser = أنشئ_محلل()
parser.description = "برنامج اختبار"

# إضافة حجة وضعية
أضف_حجة("اسم", تلميح="اسم المستخدم")

# إضافة خيار
أضف_خيار("--عمر", نوع=int, افتراضي=25)

# عرض المساعدة كما يراها المستخدم
اطبع parser.format_help()

# تحليل قائمة وسائط صريحة
المتغير args = parser.parse_args(["عمار", "--عمر", "30"])
اطبع "الاسم:", args.اسم
اطبع "العمر:", args.عمر
```
