# مكتبة تحليل الوسائط — `argparse`

مكتبة argparse الكاملة بالعربي، تحليل وسائط سطر الأوامر:

## الإنشاء

| العربي | Python | الوصف |
|--------|--------|-------|
| `أنشئ_محلل()` | `argparse.ArgumentParser()` | إنشاء محلل |
| `محلل()` | `argparse.ArgumentParser()` | محلل (مختصر) |
| `محلل_وسائط()` | `argparse.ArgumentParser()` | محلل وسائط |

## الخصائص

| العربي | Python |
|--------|--------|
| `وصف(نص)` | description |
| `تلميح_استخدام(نص)` | usage |
| `خاتمة_مساعدة(نص)` | epilog |

## المجموعات

| العربي | Python |
|--------|--------|
| `أضف_مجموعة(عنوان)` | add_argument_group |
| `مجموعة_متنافية()` | add_mutually_exclusive_group |

## الحجج

| العربي | Python |
|--------|--------|
| `أضف_حجة(اسم)` | add_argument |
| `حجة(اسم)` | add_argument |
| `أضف_خيار(اسم)` | add_argument |
| `خيار(اسم)` | add_argument |

## خصائص الحجة

| العربي | Python |
|--------|--------|
| `وجهة(اسم)` | dest |
| `نوع(نوع)` | type |
| `افتراضي(قيمة)` | default |
| `مطلوب(صحيح)` | required |
| `تلميح(نص)` | help |
| `الإجراء(فعل)` | action |
| `خيارات(قائمة)` | choices |

## الإجراءات

| العربي | Python |
|--------|--------|
| `خزن(قيمة)` | store |
| `خزن_ثابت(قيمة)` | store_const |
| `خزن_صحيح()` | store_true |
| `خزن_خطأ()` | store_false |
| `أضف(قيمة)` | append |
| `عد()` | count |
| `مساعدة()` | help |
| `إصدار(نص)` | version |

## التحليل

| العربي | Python |
|--------|--------|
| `حلل()` | parse_args |
| `حلل_وسائط()` | parse_args |
| `حلل_معروف()` | parse_known_args |

## الرسائل

| العربي | Python |
|--------|--------|
| `خطأ(رسالة)` | error |
| `خروج(حالة)` | exit |
| `اطبع_مساعدة()` | print_help |
| `اطبع_استخدام()` | print_usage |

## مثال

```apl
# إنشاء محلل
المتغير parser = أنشئ_محلل()
وصف("برنامج اختبار")

# إضافة حجة وضعية
أضف_حجة("اسم", تلم_hint="اسم المستخدم")

# إضافة خيار
أضف_خيار("--عمر", نوع=عدد_صحيح, افتراضي=25)

# تحليل الوسائط
المتغير args = حلل()
اطبع args.اسم, args.عمر
```
