# مكتبة XML — `xml.etree.ElementTree`

قراءة وبناء وتعديل وحفظ ملفات XML بالكامل بالعربي، مبنيّة على
`xml.etree.ElementTree` القياسية في Python (بدون أي مكتبة خارجية).

**106 عناصر** (51 دالة، 40 دالة كائن، 4 خصائص، 4 ثوابت، 10 معاملات) — بعد إزالة التكرار: 106 مفاتيح فريدة.

> **الفكرة:** شجرة XML = عناصر (وسوم) لكل منها **نص** و**خصائص** و**أبناء**.
> في APL تكتب `اقرأ_إكس_إم_إل("ملف.xml")` فتحصل على العنصر الجذر، ثم تتنقّل
> عبر `.ابحث_الكل` و`.نص_العنصر`، وتعدّل عبر `.عين_خاصية` و`.أضف_عنصر`،
> وتحفظ عبر `احفظ_إكس_إم_إل`.

---

## 1. القراءة والتحليل (Parsing)

| العربي | Python | الوصف |
|--------|--------|-------|
| `اقرأ_إكس_إم_إل(ملف)` | `ET.parse` | تحليل ملف → كائن `ElementTree` |
| `إكس_إم_إل_من_ملف(ملف)` | `ET.parse` | نفس الدالة (اسم بديل) |
| `اقرأ_إكس_إم_إل_آمن(ملف)` | `ET.parse` + `XMLParser` | تحليل معزول عن المراجع الخارجية |
| `إكس_إم_إل_من_نص(نص)` | `ET.fromstring` | تحليل نص → العنصر الجذر |
| `من_نص_إكس_إم_إل(نص)` | `ET.fromstring` | نفس الدالة (اسم بديل) |
| `إكس_إم_إل_من_أسطر(قائمة)` | `ET.fromstringlist` | تحليل قائمة نصوص/بايتات |
| `تحقق_من_عنصر(نص)` | `ET.fromstring` | `صواب` / `خطأ` — للفحص السريع |
| `خطأ_التحقق(نص)` | `—` | نص رسالة الخطأ، أو `""` إن كانت الصياغة سليمة |

```apl
# المقتطف مستقل: يكتب ملفه بنفسه ثم يقرأه ثم ينظّف
اكتب("_بيانات.xml", "<مكتبة><كتاب نوع='علمي'><العنوان>فيزياء</العنوان></كتاب></مكتبة>")

المتغير شجرة = اقرأ_إكس_إم_إل("_بيانات.xml")
المتغير الجذر = شجرة.جذر_الشجرة()
اطبع "الجذر:", الجذر.اسم_العنصر

لو تحقق_من_عنصر("<أ><ب/></أ>"):
    اطبع "الصياغة سليمة"
والا:
    اطبع "خطأ: " + خطأ_التحقق("<أ><ب/></أ>")

احذف_ملف("_بيانات.xml")
```

> **ملاحظة:** `اقرأ_إكس_إم_إل` تُرجع **ElementTree** (تحتاج `.جذر_الشجرة()`)،
> بينما `إكس_إم_إل_من_نص` ترجع **العنصر الجذر** مباشرة.
> هذه هي نفس التفرقة الموجودة في Python، وهي مقصودة حتى تستطيع استعمال
> `.اكتب_الشجرة` و`.جذر_الشجرة` على الناتج الأول.

## 2. الكتابة والحفظ (Serialization)

| العربي | Python | الوصف |
|--------|--------|-------|
| `إكس_إم_إل_إلى_نص(عنصر)` | `ET.tostring` | نص XML (ترميز `unicode` افتراضياً) |
| `إلى_نص_إكس_إم_إل(عنصر)` | `ET.tostring` | نفس الدالة (اسم بديل) |
| `إكس_إم_إل_إلى_نص_خام(عنصر)` | `ET.tostring` | بايتات UTF-8 (`bytes`) |
| `إكس_إم_إل_إلى_أسطر(عنصر)` | `ET.tostringlist` | قائمة أجزاء النص |
| `احفظ_إكس_إم_إل(عنصر, ملف)` | `ElementTree.write` | حفظ الشجرة إلى ملف |
| `اطبع_إكس_إم_إل(عنصر)` | `—` | طباعة الشجرة ثم إرجاعها |
| `إكس_إم_إل_قياسي(نص)` | `ET.canonicalize` | الإخراج القياسي (C14N 2.0) |
| `نسّق_إكس_إم_إل(عنصر)` | `ET.indent` + `tostring` | نص منسّق بإزاحة (**نسخة**، لا يعدّل الأصل) |
| `رتّب_الشجرة(عنصر, مسافة)` | `ET.indent` | إزاحة الشجرة نفسها (تعديل في المكان) |
| `أزل_المسافات(عنصر)` | `—` | حذف النصوص/الذيول المكوّنة من مسافات فقط |

```apl
# المقتطف مستقل: يبني العنصر بنفسه
المتغير الجذر = إكس_إم_إل_من_نص("<مكتبة><كتاب نوع='علمي'><العنوان>فيزياء</العنوان></كتاب></مكتبة>")
احفظ_إكس_إم_إل(الجذر, "_نسخة.xml")
اطبع إكس_إم_إل_إلى_نص(الجذر)                       # نص عربي مقروء
اطبع نص(إكس_إم_إل_إلى_نص_خام(الجذر))               # b'<...>' بايتات
اطبع إكس_إم_إل_قياسي("<أ  ب='1'/>")                # <أ ب="1"></أ>
احذف_ملف("_نسخة.xml")
```

**التنسيق (Pretty-printing) — الاسم لا يُضلّلك:** `ET.indent` دالة على
**المستوى الأعلى** في ElementTree، وليست دالة على العنصر، لذلك لا تكتب
`الجذر.رتّب_العنصر()` بل:

```apl
المتغير الشجرة = إكس_إم_إل_من_نص("<أ><ب><ج>1</ج></ب><د/></أ>")

اطبع نسّق_إكس_إم_إل(الشجرة)   # نص منسّق، الأصل كما هو
# <أ>
#   <ب>
#     <ج>1</ج>
#   </ب>
#   <د />
# </أ>

رتّب_الشجرة(الشجرة)           # الآن الأصل نفسه أصبح منسّقاً
اطبع إكس_إم_إل_إلى_نص(الشجرة)

أزل_المسافات(الشجرة)          # عودة إلى سطر واحد
اطبع إكس_إم_إل_إلى_نص(الشجرة)  # <أ><ب><ج>1</ج></ب><د /></أ>
```

## 3. بناء الشجرة (Building)

| العربي | Python | الوصف |
|--------|--------|-------|
| `عنصر_جديد(وسم, خصائص)` | `ET.Element` | إنشاء عنصر جذري |
| `عنصر(وسم, خصائص)` | `ET.Element` | نفس الدالة (اسم بديل) |
| `عنصر_فرعي_جديد(أب, وسم, خصائص)` | `ET.SubElement` | إنشاء ابن **وإضافته** للأب |
| `شجرة_إكس_إم_إل(عنصر)` | `ET.ElementTree` | كائن شجرة من عنصر |
| `شجرة(عنصر)` | `ET.ElementTree` | نفس الدالة (اسم بديل) |
| `باني_الشجرة()` | `ET.TreeBuilder` | باني شجرة يدوي (للمحلّلات المخصّصة) |
| `محلل_سحب(أحداث)` | `ET.XMLPullParser` | محلّل تدريجي يقرأ الأحداث |

```apl
المتغير الجذر = عنصر_جديد("مكتبة")
المتغير كتاب = عنصر_فرعي_جديد(الجذر, "كتاب", {"نوع": "علمي"})
غذِّ_نص_العنصر(كتاب, "فيزياء")
```

> **لماذا `غذِّ_نص_العنصر` بدل `كتاب.نص_العنصر = "..."`؟**
> الاثنان يعملان. الأولى تُستخدم عندما يكون العنصر تعبيراً أو داخل سطر طويل،
> والثانية (الإسناد المباشر للخاصية) أقصر وأوضح داخل الكود العادي.

## 4. دوال الكائن — البحث (Methods: search)

تُستخدم **بعد النقطة** على أي عنصر.

| العربي | Python | الوصف |
|--------|--------|-------|
| `.ابحث_عنصر(مسار)` | `.find` | أول عنصر مطابق |
| `.ابحث_الكل(مسار)` | `.findall` | كل العناصر المطابقة (قائمة) |
| `.ابحث_نص(مسار)` | `.findtext` | نص أول عنصر مطابق |
| `.كرر_بحث(مسار)` | `.iterfind` | مكرّر على العناصر المطابقة |
| `.كرر(وسم)` | `.iter` | مكرّر على العنصر وأبنائه (اختياريًا حسب الوسم) |
| `.كرر_نصوص()` | `.itertext` | مكرّر على كل النصوص |
| `.جذر_الشجرة()` | `.getroot` | الجذر من كائن `ElementTree` |
| `.اكتب_الشجرة(ملف)` | `.write` | حفظ كائن `ElementTree` |

```apl
# المقتطف مستقل: يبني شجرة صغيرة أولاً
المتغير الجذر = إكس_إم_إل_من_نص("<مكتبة><كتاب نوع='علمي'><العنوان>فيزياء</العنوان></كتاب><كتاب نوع='أدب'><العنوان>شعر</العنوان></كتاب></مكتبة>")

المتغير الكتب = الجذر.ابحث_الكل("كتاب")
اطبع الجذر.ابحث_نص(".//عنوان")

لكل كتاب في الجذر.كرر("كتاب"):
    اطبع كتاب.ابحث_نص("العنوان")
```

### صيغة المسار (XPath المختصرة)

| الصيغة | المعنى |
|--------|--------|
| `"كتاب"` | الأبناء المباشرون فقط |
| `".//كتاب"` | أي كتاب في أي مستوى (أحفاد) |
| `"كتاب[@نوع='علمي']"` | مع شرط على خاصية |
| `"*"` | أي وسم |
| `"م:عنوان"` | مع مساحة أسماء (مرّر القاموس كوسيط ثانٍ) |

| العربي | Python | الوصف |

### الصيغة الحرة (بدون نقطة)

كل دوال الكائن لها مقابل «حر» يُمرَّر العنصر كأول وسيط، مفيد داخل
التعابير المركّبة وفي أنماط البرمجة الوظيفية:

| الحر | يكافئ |
|------|-------|
| `اقرأ_خاصية(ع, اسم)` | `ع.اقرأ_خاصية(اسم)` |
| `عين_خاصية(ع, اسم, قيمة)` | `ع.عين_خاصية(اسم, قيمة)` |
| `تضيف(أب, ابن)` | `أب.أضف_عنصر(ابن)` |
| `تحذف(أب, ابن)` | `أب.احذف_عنصر(ابن)` |
| `تفرغ(ع)` | `ع.أفرغ_العنصر()` |
| `تنسخ(ع)` | `انسخ_العنصر(ع)` |
| `تجد(ع, مسار)` | `ع.ابحث_عنصر(مسار)` |
| `تجد_الكل(ع, مسار)` | `ع.ابحث_الكل(مسار)` |
| `تجد_نص(ع, مسار)` | `ع.ابحث_نص(مسار)` |
| `غذِّ_نص_العنصر(ع, نص)` | `ع.نص_العنصر = نص` |
| `غذِّ_ذيل_العنصر(ع, نص)` | `ع.ذيل_العنصر = نص` |
| `أعد_تسمية(ع, وسم)` | `ع.اسم_العنصر = وسم` (الاسم البديل: `عين_وسم`) |
| `عين_خصائص(ع, قاموس)` | استبدال كل الخصائص دفعة واحدة |

## 9. الأحداث والباني والمحلل التدريجي

### الباني `TreeBuilder`

| العربي | Python |
|--------|--------|
| `ابدأ_وسم(وسم, خصائص)` / `ابدأ_عنصر(...)` | `.start` |
| `أنهِ_وسم(وسم)` / `أنهِ_عنصر(...)` | `.end` |
| `غذِّ_نص(نص)` / `غذِّ(نص)` / `غذِّ_العنصر(نص)` | `.data` |
| `غذِّ_نص_العنصر(نص)` | `.data` |
| `تعليق_باني(نص)` | `.comment` |
| `تعليمات_باني(هدف, نص)` | `.pi` |
| `أغلق_الشجرة()` / `أغلق_الباني()` | `.close` |

```apl
المتغير باني = باني_الشجرة()
باني.ابدأ_وسم("مذكرة", {})
باني.غذِّ_نص("مرحباً")
باني.أنهِ_وسم("مذكرة")
المتغير شجرة = شجرة_إكس_إم_إل(باني.أغلق_الشجرة())
اطبع إكس_إم_إل_إلى_نص(شجرة.جذر_الشجرة())
```

### المحلل التدريجي `XMLPullParser`

| العربي | Python |
|--------|--------|
| `محلل_سحب(أحداث = [...])` | `ET.XMLPullParser` |
| `غذِّ_المحلل(نص)` / `غذِّ_شجرة(نص)` | `.feed` |
| `اقرأ_الأحداث()` / `أحداث_المحلل()` | `.read_events` |
| `أغلق_المحلل()` / `أغلق_الشجرة()` | `.close` |

```apl
المتغير محلل = محلل_سحب(أحداث = [حدث_بداية])
محلل.غذِّ_المحلل("<أ><ب/></أ>")
لكل زوج في محلل.اقرأ_الأحداث():
    اطبع زوج[0] + " → " + زوج[1].اسم_العنصر
محلل.أغلق_المحلل()
```

> `اقرأ_الأحداث()` و`كرر()` و`كرر_نصوص()` تُرجع **مكرّرات (iterators)**،
> فاستخدم `قائمة(...)` قبل `طول(...)` أو الفهرسة:
> `اطبع طول(قائمة(الجذر.كرر("كتاب")))`.

> **تنبيه مهم:** في APL تُترجم `لكل س في كائن:` إلى
> `for س in كائن:` مباشرة. وعنصر XML القياسي **قابل للتكرار** فيعطي أبناءه،
> لذلك `لكل ابن في الجذر:` تمرّ على الأبناء. أما إن أردت المرور على **كل**
> العناصر (بما فيها الجذر والأحفاد) فاكتب `لكل ع في الجذر.كرر():` — أو
> `قائمة(الجذر.كرر())` إن احتجت القائمة نفسها.

## 10. مساحات الأسماء (Namespaces)

```apl
سجل_مساحة_أسماء("م", "http://example.com/library")

المتغير الجذر = إكس_إم_إل_من_نص(
    "<م:مكتبة xmlns:م='http://example.com/library'><م:كتاب/></م:مكتبة>"
)
اطبع مساحة_أسماء(الجذر.اسم_العنصر)          # http://example.com/library

المتغير قاموس = {"م": "http://example.com/library"}
لكل عنوان في الجذر.ابحث_الكل(".//م:كتاب", قاموس):
    اطبع عنوان.اسم_العنصر
```

- الاسم الكامل للوسم في ElementTree يكون `{uri}الاسم`.
- `اقرأ_خاصية` تقبل الاسم الكامل: `اقرأ_خاصية(كتاب, "{" + المساحة + "}الرقم")`.
- `سجل_مساحة_أسماء` يجعل الإخراج يستخدم البادئة بدل `ns0:`.

## 13. الأمان والملاحظات

1. **لا مكتبة خارجية** — كل شيء عبر `xml.etree.ElementTree` القياسية.
2. **تحميل كسول** — البرامج التي لا تستخدم XML لا تدفع أي كلفة إقلاع.
3. **ترميز يونيكود** — `إكس_إم_إل_إلى_نص` ترجع `str` عربياً مقروءاً؛
   استخدم `إكس_إم_إل_إلى_نص_خام` إن أردت `bytes`.
4. **هجمات XXE** — المعالجة القياسية في ElementTree لا تحلّل الكيانات
   الخارجية، و`اقرأ_إكس_إم_إل_آمن` تمنحك محلّلاً صريحاً (`XMLParser`).
5. **أسماء عربية للوسوم مطلوبة؟** يعمل معها ElementTree، لكن أدوات XML
   الخارجية قد تتوقّع أسماء لاتينية؛ الأسماء العربية مدعومة ومختبرة.
