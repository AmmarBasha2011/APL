# مرجع اللغة — APL

## المتغيرات

```apl
المتغير اسم = "عمار"
المتغير عمر = 25
المتغير س = صحيح(ادخل("رقم: "))
```

## الطباعة والإدخال

```apl
اطبع "مرحبا"                      # print("مرحبا")
اطبع "الاسم:", اسم                # print("الاسم:", اسم)
اطبع_بدون "نص"                    # print("نص", end="")
المتغير اسم = ادخل("ما اسمك؟ ")   # name = input("ما اسمك؟ ")
```

## الشروط

```apl
لو عمر >= 18:
    اطبع "بالغ"
الا لو عمر > 12:
    اطبع "مراهق"
الا:
    اطبع "طفل"

# شرط ثلاثي
المتغير ن = 1 إذا صواب والا 0

# عامل الحوت (Walrus operator)
لو (ن = طول(قائمة)) > 5:
    اطبع "كبير"
```

## الحلقات

```apl
طالما س < 10:
    اطبع س

لكل i في نطاق(5):
    اطبع i

أبدا:                               # while True
    اطبع "تكرار"
```

## List Comprehensions

```apl
# [تعبير لكل عنصر في تسلسل]
المتغير مربعات = [س*س لكل س في نطاق(1, 6)]

# مع شرط
المتغير زوجي = [س لكل س في نطاق(1, 11) لو س % 2 == 0]
```

## الدوال

```apl
دالة جمع(أ, ب):
    ارجع أ + ب

المتغير ضعف = سهم س: س * 2         # lambda

# Type Hints
دالة جمع(أ: صحيح, ب: صحيح) -> صحيح:
    ارجع أ + ب
```

## الفئات (Classes)

```apl
صنف شخص:
    دالة __init__(ذات, اسم):
        ذات.اسم = اسم
    دالة سلام(ذات):
        اطبع "مرحبا", ذات.اسم

صنف طالب(شخص):                      # وراثة
    تمرير
```

## معالجة الأخطاء

```apl
حاول:
    المتغير س = صحيح(ادخل("رقم: "))
إمسك ValueError:
    اطبع "رقم غير صحيح"
```

## الملفات

## التواريخ

```apl
# دوال
المتغير الآن = الآن()           # التاريخ والوقت الحالي
المتغير اليوم = اليوم()          # التاريخ الحالي

# خصائص (بدون اطبع)
اطبع "السنة:", سنة_الآن
اطبع "الشهر:", شهر_الآن
اطبع "اليوم:", يوم_الآن
اطبع "الساعة:", ساعة_الآن
اطبع "الدقيقة:", دقيقة_الآن
اطبع "الثانية:", ثانية_الآن

# الانتظار
وقت_نومي(1)              # انتظر ثانية
```

## التطابق (Match/Case)

```apl
# تطابق أساسي
حالة اختيار:
    قيمة 1:
        اطبع "واحد"
    قيمة 2:
        اطبع "اثنان"
    افتراضي:
        اطبع "غير معروف"

# تطابق مع شرط (guard clause)
حالة ن:
    قيمة 0:
        اطبع "صفر"
    قيمة ن لو ن > 0:
        اطبع "موجب"
    افتراضي:
        اطبع "سالب"
```

## المزخرفات (Decorators)

```apl
خاصية اسم                         # @property
محدد اسم                          # @name.setter
محدد_حذف اسم                      # @name.deleter

# مزخرف مع حجج
مزخرف(حجة1, حجة2)
دالة مثال():
    اطبع "مزخرف"
```

## العام/خاص

```apl
خاص المتغير سر = 123              # __سر = 123
خاص دالة د_سر():                   # def __د_سر()
عام المتغير ظاهر = "علني"         # ظاهر = "علني"
عام دالة د_ظاهر():                 # def د_ظاهر()
```

## إدارة السياق (Context Managers)

```apl
مع فتح("ملف.txt") مثل f:
    اطبع f.read()

# أو بالإنجليزي
with open("file.txt") as f:
    print(f.read())
```

## الفواصل المنقوطة (Semicolons)

```apl
# أو بدون ;
المتغير س = 5
اطبع س
```
