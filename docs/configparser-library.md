# مكتبة ملفات الإعداد — `configparser`

مكتبة configparser الكاملة بالعربي، قراءة وكتابة ملفات الإعداد:

## الإنشاء

| العربي | Python | الوصف |
|--------|--------|-------|
| `أنشئ_مُكوِّن()` | `configparser.ConfigParser()` | إنشاء مُكوِّن |
| `مُكوِّن()` | `configparser.ConfigParser()` | مُكوِّن (مختصر) |
| `مُكوِّن_إعدادات()` | `configparser.ConfigParser()` | مُكوِّن إعدادات |
| `إعدادات()` | `configparser.ConfigParser()` | إعدادات (مختصر) |

## القراءة

| العربي | Python |
|--------|--------|
| `اقرأ(ملف)` | read |
| `اقرأ_ملف(ملف)` | read_file |
| `اقرأ_سلسلة(نص)` | read_string |
| `اقرأ_قاموس(قاموس)` | read_dict |

## الكتابة

| العربي | Python |
|--------|--------|
| `اكتب(ملف)` | write |
| `اكتب_ملف(ملف)` | write |

## الأقسام

| العربي | Python |
|--------|--------|
| `أضف_قسم(قسم)` | add_section |
| `أزل_قسم(قسم)` | remove_section |
| `يوجد_قسم(قسم)` | has_section |
| `الأقسام()` | sections |

## الخيارات

| العربي | Python |
|--------|--------|
| `ضع(قسم, خيار, قيمة)` | set |
| `احصل(قسم, خيار)` | get |
| `أزل_خيار(قسم, خيار)` | remove_option |
| `يوجد_خيار(قسم, خيار)` | has_option |
| `الخيارات(قسم)` | options |

## أنواع البيانات

| العربي | Python |
|--------|--------|
| `احصل_عدد_صحيح(قسم, خيار)` | getint |
| `احصل_عدد_عشري(قسم, خيار)` | getfloat |
| `احصل_منطقي(قسم, خيار)` | getboolean |

## التعيينات

| العربي | Python |
|--------|--------|
| `items(قسم)` | items |
| `احصل_كل(قسم)` | items |

## مثال

```apl
# إنشاء مُكوِّن
المتغير config = أنشئ_مُكوِّن()

# إضافة قسم
أضف_قسم("قاعدة_بيانات")
ضع("قاعدة_بيانات", "مضيف", "localhost")
ضع("قاعدة_بيانات", "منفذ", "5432")
ضع("قاعدة_بيانات", "اسم", "mydb")

أضف_قسم("مستخدم")
ضع("مستخدم", "اسم", "admin")
ضع("مستخدم", "عمر", "25")

# كتابة الملف
المتغير f = open("config.ini", "w")
اكتب(f)
f.close()

# قراءة الملف
المتغير config2 = أنشئ_مُكوِّن()
اقرأ("config.ini")

# الحصول على قيم
المتغير المضيف = احصل("قاعدة_بيانات", "مضيف")
المتغير المنفذ = احصل_عدد_صحيح("قاعدة_بيانات", "منفذ")
```
