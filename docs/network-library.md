# مكتبة الشبكة والبريد — `net`

مقابس TCP/UDP، اتصالات TLS، عميل وخادم HTTP، بناء رسائل البريد وإرسالها،
POP3/IMAP/FTP، حسابات عناوين IP، وتغليف البيانات الثنائية — كلها بالعربي
وبدون أي مكتبة خارجية، على حزمة Python القياسية فقط.

**1006 عنصر** (222 دالة، 356 دالة كائن، 91 خاصية، 311 ثابتاً، 26 معاملاً عربياً) —
كل اسم فريد، و**صفر تعارض** مع المكتبات الـ 43 الأخرى أو مع نواة اللغة.

> **الفكرة:** كل ما في الشبكة يبدأ من عنوان ومنفذ. تكتب
> `مقبس_شبكة(عائلة_ipv4, مقبس_تدفق)` فتحصل على مقبس، تربطه بمنفذ بـ
> `ربط_المنفذ`، وتستمع بـ `استمع_للاتصالات`، ثم `اقبل_اتصال` للخادم أو
> `اتصل_بالعنوان` للعميل. وفوق هذه الطبقة: `سياق_آمن_افتراضي` للتشفير،
> `اتصال_http` للويب، `رسالة_بريد_كاملة` للبريد، `عنوان_ip` للحسابات.
>
> **تصميم:** لا شيء يُستورد عند بدء التشغيل. البرنامج الذي لا يلمس الشبكة لا
> يدفع ثمنها: سطر `import socket` لا يُضاف إلا إذا ظهرت كلمة من المكتبة في
> الكود المترجَم، ويُضاف كل موديول على حدة.

## 2. المقابس: خادم وعميل TCP على نفس الجهاز

| العربي | Python | الوصف |
|--------|--------|-------|
| `مقبس_شبكة(عائلة, نوع)` | `socket.socket` | مقبس جديد |
| `زوج_مقابس()` | `socketpair` | مقبسان متصلان (للتجربة) |
| `اتصال_شبكة(عنوان, مهلة_اتصال=)` | `create_connection` | عميل جاهز بنداء واحد |
| `خادم_شبكة(عنوان)` | `create_server` | خادم جاهز بنداء واحد |
| `أغلق_مقبس(م)` | `close` | يقبل المقبس أو رقم الوصف |
| `عين_مهلة_افتراضية(ث)` | `setdefaulttimeout` | مهلة كل المقابس |
| `مقبس_من_وصف(رقم, عائلة, نوع)` | `fromfd` | من رقم وصف موجود |

**دوال الكائن:**

| العربي | Python | الوصف |
|--------|--------|-------|
| `ربط_المنفذ(عنوان)` | `bind` | ربط بعنوان ومنفذ |
| `استمع_للاتصالات(عدد)` | `listen` | بدء الاستماع |
| `اقبل_اتصال()` | `accept` | يُرجع `(مقبس, عنوان)` |
| `اتصل_بالعنوان(عنوان)` | `connect` | اتصال كعميل |
| `اتصل_وأرجع_الخطأ(عنوان)` | `connect_ex` | يُرجع رقم الخطأ بدل الاستثناء |
| `أرسل_بيانات(بايتات)` | `send` | إرسال (قد ينقص) |
| `أرسل_الكل(بايتات)` | `sendall` | إرسال كامل |
| `استقبل(حجم)` | `recv` | استقبال بايتات |
| `استقبل_من(حجم)` | `recvfrom` | مع عنوان المرسل (UDP) |
| `أرسل_إلى_عنوان(بايتات, عنوان)` | `sendto` | إرسال إلى عنوان (UDP) |
| `عين_مهلة(ث)` / `اقرأ_المهلة()` | `settimeout` / `gettimeout` | مهلة هذا المقبس |
| `عين_الحجب(منطقي)` | `setblocking` | حجب/عدم حجب |
| `عين_خيار(مستوى, خيار, قيمة)` | `setsockopt` | خيارات المقبس |
| `عنوان_المقبس()` / `عنوان_الطرف_الآخر()` | `getsockname` / `getpeername` | العنوانان |
| `رقم_الوصف()` | `fileno` | رقم الوصف |
| `افتح_ملف_من_المقبس()` | `makefile` | ملف للقراءة/الكتابة |
| `أغلق_اتجاه(اتجاه)` | `shutdown` | إغلاق اتجاه واحد |
| `أغلق_المقبس()` | `close` | إغلاق |
| `أرسل_ملف(ملف, عدد)` | `sendfile` | إرسال ملف بسرعة |

```apl
# خادم يستمع على منفذ يختاره النظام
خ = مقبس_شبكة(عائلة_ipv4, مقبس_تدفق)
خ.عين_خيار(مستوى_المقبس, إعادة_استخدام_العنوان, 1)
خ.ربط_المنفذ(("127.0.0.1", 0))
خ.استمع_للاتصالات(1)
العنوان = خ.عنوان_المقبس()
اطبع "الخادم على", العنوان

# العميل يتصل، والخادم يقبل
ع = اتصال_شبكة(العنوان, مهلة_اتصال = 5)
ج, طرف = خ.اقبل_اتصال()
اطبع "وصل:", طرف

ع.أرسل_الكل("أهلاً بالشبكة".encode())
اطبع "استلم الخادم:", ج.استقبل(1024).decode()

ج.أغلق_المقبس()
ع.أغلق_المقبس()
خ.أغلق_المقبس()
```

**نصيحة عملية:** `send` قد يرسل أقل من المطلوب؛ استخدم `أرسل_الكل` دائماً إلا
إذا كنت تدير الإرسال الجزئي بنفسك. و`استقبل(حجم)` ينتظر حتى تصل بيانات أو
يُغلق الطرف الآخر، فحدّد `عين_مهلة` إن كان الانتظار قد يطول.

## 3. UDP: رسائل بلا اتصال

| العربي | Python | الوصف |
|--------|--------|-------|
| `مقبس_بيانات` | `SOCK_DGRAM` | نوع المقبس لـ UDP |
| `أي_عنوان` | `INADDR_ANY` | استقبل على كل الواجهات |
| `عنوان_بث` | `INADDR_BROADCAST` | عنوان البث |
| `استقبل_من(حجم)` | `recvfrom` | البيانات + عنوان المرسل |
| `أرسل_إلى_عنوان(بيانات, عنوان)` | `sendto` | إرسال رسالة واحدة |

```apl
# مستمع UDP على منفذ حر
خ = مقبس_شبكة(عائلة_ipv4, مقبس_بيانات)
خ.ربط_المنفذ(("127.0.0.1", 0))
عنوان_الاستماع = خ.عنوان_المقبس()

# مُرسِل
ع = مقبس_شبكة(عائلة_ipv4, مقبس_بيانات)
ع.عين_مهلة(3)
ع.أرسل_إلى_عنوان("رسالة سريعة".encode(), عنوان_الاستماع)

بيانات, مرسل = خ.استقبل_من(1024)
اطبع "من", مرسل, ":", بيانات.decode()

ع.أغلق_المقبس()
خ.أغلق_المقبس()
```

UDP لا يضمن الوصول ولا الترتيب: إن أردت ضماناً فاستخدم TCP، وإن أردت بثاً
لمجموعة فاستخدم `انضم_للمجموعة` مع `عنوان_متعدد_بث`.

## 4. الجاهزية: انتظر عدة مقابس معاً

| العربي | Python | الوصف |
|--------|--------|-------|
| `انتظر_جاهزية(قراءة, كتابة, استثناء, مهلة)` | `select.select` | ينتظر جاهزية أي مقبس |
| `محدد_جاهزية()` | `selectors.DefaultSelector` | المحدد الأمثل للنظام |
| `سجّل_مقبس(م, أحداث, بيانات)` | `register` | إضافة مقبس للمحدد |
| `اقرأ_الجاهز(مهلة)` | `select` | أحداث جاهزة |
| `ألغِ_تسجيل(م)` | `unregister` | إزالة |
| `مهيّئ_استطلاع()` | `select.poll` | استطلاع (Linux) |
| `مهيّئ_epoll()` | `select.epoll` | epoll (Linux) |
| `حدث_قراءة` / `حدث_كتابة` | `EVENT_READ` / `EVENT_WRITE` | أنواع الأحداث |

```apl
ا1, ا2 = زوج_مقابس()

# select: من جاهز الآن؟
جاهز, _, _ = انتظر_جاهزية([ا1], [], [], 0.2)
اطبع "جاهز للقراءة قبل الإرسال:", طول(جاهز)

ا2.أرسل_الكل("بيانات".encode())
جاهز, _, _ = انتظر_جاهزية([ا1], [], [], 1)
اطبع "جاهز بعد الإرسال:", طول(جاهز)
اطبع "المحتوى:", جاهز[0].استقبل(100).decode()

# selectors: نفس الفكرة بواجهة أنظف
منتقي = محدد_جاهزية()
منتقي.سجّل_مقبس(ا1, حدث_قراءة, "الأول")
ا2.أرسل_الكل("ثانٍ".encode())
لكل مفتاح, أحداث في منتقي.اقرأ_الجاهز(1):
    اطبع "البيانات المرافقة:", مفتاح.بيانات_المفتاح
    مفتاح.ملف_المفتاح.استقبل(100)
منتقي.أغلق_المحدد()

ا1.أغلق_المقبس()
ا2.أغلق_المقبس()
```

```apl
س = سياق_آمن_افتراضي()

# سياق بلا تحقق للتجربة المحلية فقط
س2 = سياق_آمن_افتراضي(تحقق = خطأ)

اطبع "tls1.3 متاح:", يدعم_tls13
```

## 6. عميل HTTP

|--------|--------|-------|
| `اتصال_http(خادم, منفذ=)` | `HTTPConnection` | اتصال HTTP عادي |

| `اقرأ_الاستجابة()` | `getresponse` | استجابة للقراءة |
| `حالة_الاستجابة` | `status` | 200، 404، … |
| `رؤوس_الاستجابة` | `headers` | رؤوس الاستجابة |
| `اقرأ_جسم_الاستجابة(حجم)` | `read` | جسم الاستجابة |
| `افتح_رابط(عنوان)` | `urlopen` | جلب رابط بنداء واحد |
| `طلب_ويب(عنوان, بيانات=)` | `Request` | طلب ككائن (رؤوس، طريقة) |
| `جلب_رابط_لملف(عنوان, ملف)` | `urlretrieve` | تنزيل مباشر إلى ملف |

| `فاتح_وكيل(بروكسي)` | `ProxyHandler` | المرور عبر بروكسي |
| `فاتح_كوكيز` / `مدير_كوكيز` | `HTTPCookieProcessor` / `CookieJar` | إدارة الكوكيز |
| `معرّف_حالة_موافق` / `حالة_غير_موجود` / `معرّف_حالة_محظور` … | `HTTPStatus` | أكواد الحالة بالأسماء |

```apl
# خادم HTTP محلي داخل نفس البرنامج: لا حاجة إلى إنترنت
خ = مقبس_شبكة(عائلة_ipv4, مقبس_تدفق)
خ.عين_خيار(مستوى_المقبس, إعادة_استخدام_العنوان, 1)
خ.ربط_المنفذ(("127.0.0.1", 0))
خ.استمع_للاتصالات(1)
_, المنفذ = خ.عنوان_المقبس()

# العميل يرسل الطلب أولاً (يُخزَّن في نواة النظام حتى يقبل الخادم)
ع = اتصال_http("127.0.0.1", المنفذ)
ع.أرسل_طلب("GET", "/ترحيب")
```

## 15. الأمان والملاحظات

**1. التحقق من الشهادات مفتوح على مصراعيه في `تحقق = خطأ`.** استخدمه في
التجربة المحلية فقط. في الإنتاج: `سياق_آمن_افتراضي()` وحده (التحقق الافتراضي
إلزامي وفحص الاسم مفعّل).

**2. لا تبنِ عناوين من مدخلات المستخدم بلا تحقق.** `بيانات_العنوان` قد تُرجع
عناوين داخلية؛ تحقّق من النتيجة إن كان الاسم قادماً من خارج البرنامج.

**3. `استقبل(حجم)` لا يعني "الرسالة كاملة".** قد تصل البيانات على دفعات. عند
وجود رأس طول (Content-Length) اقرأ الطول المعلن، أو استخدم `افتح_ملف_من_المقبس`
مع `قراءة_الكل`.

**4. أغلق ما تفتحه.** كل `مقبس_شبكة` أو `اتصال_http` أو `عميل_smtp` يحتاج
`أغلق_المقبس` / `أغلق_الاتصال` / `أغلق_الاتصال`. النسخة الآمنة:

```apl
# الإغلاق مضمون في الحالتين: نجاح أو فشل — بلا try/finally
دالة اقرأ_الحالة(عنوان, منفذ):
    ع = اتصال_http(عنوان, منفذ, مهلة_اتصال_http = 1)
    حاول:
        ع.أرسل_طلب("GET", "/")
        الحالة = ع.اقرأ_الاستجابة().حالة_الاستجابة
        ع.أغلق_الاتصال()
        ارجع الحالة
    إمسك مثل مشكلة:
        اطبع "فشل الاتصال:", مشكلة
        ع.أغلق_الاتصال()
        ارجع 0

اطبع "النتيجة:", اقرأ_الحالة("127.0.0.1", 9)
```

**5. المنافذ الأقل من 1024 تحتاج صلاحيات.** للتجربة استخدم منفذاً يختاره النظام
(`ربط_المنفذ(("127.0.0.1", 0))`) ثم اقرأه بـ `عنوان_المقبس()`.

**6. المهلة ليست رفاهية.** أي مقبس بلا `عين_مهلة` قد ينتظر إلى الأبد. الافتراضي
في `اتصال_شبكة` و`اتصال_http` موجود، لكن المقابس اليدوية بلا مهلة.

## 16. أسئلة شائعة

**هل تعمل المكتبة بلا إنترنت؟**
نعم. كل الأمثلة في هذه الصفحة تعمل محلياً: المقابس والحسابات وبناء الرسائل
وخوادم HTTP المحلية. ما يحتاج إنترنت هو الاتصال بخادم خارجي فقط.

**لماذا `مقبس_شبكة` وليس `مقبس`؟**
لأن `مقبس` محجوز لمكتبة fastapi. القاعدة ثابتة في APL: أول مكتبة تحجز الاسم
تحتفظ به، والمكتبات التالية تشتق اسماً جديداً.

**هل أستطيع استخدام `socket` مباشرة؟**
نعم. الكلمات العربية تُترجم إلى نداءات Python عادية، فيمكنك مزج
`مقبس_شبكة(عائلة_ipv4, مقبس_تدفق)` مع `socket.setsockopt` كما تشاء.

**ما الفرق بين `بيانات_الاسم` و`عنوان_الاسم`؟**
`عنوان_الاسم` يُرجع عنوان IPv4 واحداً (بسيط وسريع). `بيانات_الاسم` يُرجع قائمة
كاملة فيها العائلة والنوع والبروتوكول والعنوان — وهي ما يحتاجه برنامج يحاول
IPv6 أولاً ثم IPv4.

**لماذا `طول(جاهز)` يساوي صفراً أحياناً؟**
`انتظر_جاهزية` تُرجع فقط المقابس الجاهزة الآن؛ صفر يعني انتهت المهلة بلا حدث.
زد المهلة أو تحقق من أن الطرف الآخر أرسل فعلاً.

**هل `الاستجابة.حالة_الاستجابة` نص أم عدد؟**
عدد صحيح (200، 404). استخدم `سبب_الحالة` للنص ("OK").

**كيف أتعامل مع UTF-8؟**
`.encode("utf-8")` عند الإرسال و`.decode("utf-8")` عند الاستقبال. الافتراضي في
Python هو UTF-8، لكن التصريح به يمنع المفاجآت.

**هل المكتبة تضيف وقتاً لتشغيل برنامج لا يستخدم الشبكة؟**
لا. قياس فعلي: `اطبع 1` = 66 ms مع المكتبة، 63.6 ms قبلها — فرق داخل حدود
الضجيج، لأن الاستيراد لا يحدث إلا عند ظهور كلمة من المكتبة في الكود المترجَم.
