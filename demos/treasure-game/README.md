# كنز الواحة — لعبة مغامرة نصية بـ APL

مشروع تجريبي صغير مكتوب بالكامل بالعربي، يعرض أكثر من ميزة في اللغة: الأصناف، الدوال، القواميس، القوائم، الحلقات، `حاول`/`إمسك`، والإدخال التفاعلي.

## التشغيل

```bash
python apl.py demos/treasure-game/game.apl
```

## الهدف

اجمع الحبل من الواحة، والمفتاح من الخيمة، انزل البئر بالحبل لتأخذ الذهب، ثم ارجع إلى الكهف واكتب `افتح`.

## الأوامر

| الأمر | الوظيفة |
|-------|---------|
| `شمال` `جنوب` `شرق` `غرب` | التنقل |
| `خذ` | أخذ الغرض الموجود في المكان |
| `افتح` | فتح الصندوق (في الكهف) |
| `حقيبة` | عرض ما تحمله |
| `وصف` | وصف المكان |
| `مساعدة` | عرض الأوامر |
| `خروج` | إنهاء اللعبة |

## الاختبار

```bash
python demos/treasure-game/test_game.py
```

## الخريطة

```
        الخيمة
          |
 الكهف — الواحة      (الكهف شرق الواحة، والخيمة شمالها)
   |
 البئر
```
