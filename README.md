# APL — لغة عمار البرمجية

لغة برمجة عربية مبنية على Python. الكود بيتكتب بالعربي، وبيتحوّل لـ Python نظيف ويشتغل.
اللغة نفسها مش محتاجة أي مكتبة خارجية، ومبنية على مكتبة Python القياسية بس.

**التوثيق الرسمي الكامل: [APL-Docs](https://github.com/AmmarBasha2011/APL-Docs)**

## التثبيت

اللغة شغالة بـ Python 3.9 أو أحدث، من غير أي حزمة إضافية:

```
git clone https://github.com/AmmarBasha2011/APL.git
cd APL
python apl.py نسخة
```

أو نزّل الملف التنفيذي من تبويب Actions (بناء يدوي، ويندوز ولينكس، بدون ماك).

حزمة ويندوز ولينكس (نسخة Alpha) فيها كمان برامج مرافقة، كل واحد بملف تدوس عليه مرتين:

| البرنامج | بيعمل إيه |
|---|---|
| APL-Terminal (`عمار محطة`) | طرفية عادية بتقرأ وتكتب العربي صح، من غير ما تدخل على اللغة |
| APL-REPL (`عمار طرفية`) | جرب أوامر APL مباشرة |
| APL-Libraries (`عمار معرض-المكتبات`) | صفحة المكتبات المعتمدة في المتصفح |
| APL-Docs (`عمار توثيق`) | التوثيق بدون نت، ولما فيه نت بيحمّل الملفات اللي اتغيرت بس |
| APL-Examples (`عمار أمثلة`) | تصفح الأمثلة وانسخها وشغلها |
| APL-Benchmark (`عمار قياس`) | قياس سرعة APL مقارنة بـ Python |

## أول برنامج

```
اطبع "أهلاً بالعالم"
```

شغّله بـ:

```
عمار شغل hello.apl
```

## أوامر "عمار"

| الأمر | اللي بيعمله |
|---|---|
| `عمار شغل ملف.apl` | تشغيل برنامج |
| `عمار فحص ملف.apl` | فحص الصياغة بدون تشغيل |
| `عمار ترجمة ملف.apl` | طباعة كود Python المترجم |
| `عمار طرفية` أو `عمار` لوحده | موجّه تفاعلي |
| `عمار -c 'كود'` | تنفيذ كود مباشرة |
| `عمار نسخة` | رقم الإصدار |
| `عمار مساعدة` | المساعدة |
| `عمار مسح-الكاش [مسار]` | حذف الترجمات المخزنة هنا وفي جذر المشروع، أو في المسار المحدد |
| `عمار تنسيق ملف.apl` | تنسيق الكود (و`--كتابة` يحفظ في الملف) |
| `عمار مسار ثبت` | إضافة عمار للـ PATH عشان يشتغل من أي مجلد |
| `عمار بناء ملف.apl` | ملف تنفيذي مستقل للبرنامج (`--اسم` يحدد اسمه) |
| `عمار تتبع ملف.apl` | طباعة كل سطر APL بيتنفّذ وانت شايف النتيجة |
| `عمار مصحح ملف.apl` | مصحح خطوة بخطوة (`--توقف 3,7` نقط توقف) |
| `عمار مشروع جديد <اسم>` | مجلد مشروع جديد جاهز للتشغيل |
| `عمار مشروع تشغيل` | تشغيل المشروع اللي في المجلد الحالي |
| `عمار مكتبة ...` | إدارة المكتبات (تحت) |
| `عمار مثال ...` | إدارة الأمثلة (تحت) |

في `editors/` فيه دعم المحررات: تلوين للـ VS Code، وسيرفر لغة (LSP) بيشتغل مع أي
محرر بيدعم LSP، بيدي أخطاء المترجم نفسها واقتراحات وشرح للكلمات. التفاصيل في
`editors/lsp/README.md`.

وعشان تجرّب من غير أي تثبيت: **المختبر** في `playground/index.html` بيشغّل
المفسّر جوه المتصفح (WebAssembly)، فبتكتب كود عربي وتشوف النتيجة على طول.
نسخة جاهزة على: <https://ammarbasha2011.github.io/APL/playground/>

## ميزات اللغة

- معالجة الأخطاء: `حاول:` / `امسك مثل خطأ:` / `أخيراً:`
- رسائل أخطاء عربية برقم السطر والعمود.
- الأصناف والكائنات: `صنف` / `دالة_إنشاء` / `ذات`، ومعاها الوراثة.
- استيراد ملف APL تاني: `استورد "ملف.apl"`.
- ملفات وإدخال: `اقرأ` / `اكتب` / `ادخل`.
- دوال مختصرة `(س) => س * 2`، فهم القوائم `[ع * 2 لكل ع في قائمة]`، ونصوص منسّقة `"أهلاً {الاسم}"`.
- كلمات التحكم: `لو` / `والا` / `لكل` / `طالما` / `ارجع` / `توقف` / `اكمل` / `قيمة` (match).
- أرقام عربية: `٢+٢` تساوي `2+2`، والنص بيفضل زي ما هو.
- `عمار فحص` بيدّي تنبيهات (تاب، مسافات زيادة، `=` جوه شرط، TODO) مع فحص الصياغة.

## المكتبات

اللغة مابتشحنش أي مكتبة. المكتبات ريبوهات GitHub مستقلة، ومدير الحزم بيجيبها.

```
عمار مكتبة تحميل <اسم>        # من AmmarBasha2011/apl-<اسم>
عمار مكتبة تحميل مالك/ريبو    # من أي ريبو GitHub
عمار مكتبة تحميل <رابط>       # من رابط GitHub كامل
عمار مكتبة قائمة              # المثبتة
عمار مكتبة بحث <كلمة>         # بحث محلي وعلى GitHub
عمار مكتبة تحميل <اسم> --بدون-اعتمادات   # من غير تسطيب حزم Python
عمار مكتبة حذف <اسم>
عمار مكتبة قفل                # إصدارات المثبتة (lockfile)
عمار مكتبة استعادة            # رجّع المثبتة زي ما هي في القفل
```

التثبيت بينزّل الريبو، يقرأ `apl-library.json`، يتأكد إن ملف الكود بيترجم، وينسخه في
`~/.apl/libraries/<الاسم>/`. التثبيت **مابيشغّلش** كود المكتبة؛ الكود بيشتغل وقت
الاستخدام بصلاحياتك، فالمصدر بيظهر في رسالة التثبيت.

### تثبيت إصدار معيّن والقفل

```
عمار مكتبة تحميل tabulate@1.0.0     # tag اسمه v1.0.0
عمار مكتبة تحميل tabulate==1.0.0     # نفس الحاجة
```

تثبيت المكتبة بيسطّب حزم Python اللي هي محتاجاها (بيقولك بالظبط إيه اللي هيتسطّب
قبل ما يبدأ، وبيرفض أي مواصفات مش اسم حزمة عادي). لو مش عايزها استخدم
`--بدون-اعتمادات`. من غير إصدار بياخد أحدث نسخة من `main`. كل تثبيت بيتسجّل في `~/.apl/lock.json`:
الاسم، الإصدار، المصدر، والمكتبات اللي المكتبة محتاجاها. `عمار مكتبة قفل` بيطبع
الملف، و`عمار مكتبة استعادة` بينزّل أي مكتبة مسجّلة في القفل بإصدارها بالظبط —
على جهاز تاني، أو بعد ما مجلدها يضيع. حذف مكتبة بيشيل سطرها من القفل.

### إنشاء مكتبة بنفسك

1. اعمل ريبو GitHub عام، الاسم المقترح `apl-<اسم المكتبة>`.
2. حط فيه ملف `apl-library.json`:

```json
{
  "name": "mylib",
  "version": "1.0.0",
  "title": "مكتبة mylib",
  "description": "كلمات عربية لـ ...",
  "entry": "mylib_funcs.py",
  "requires": [],
  "license": "PSF-2.0",
  "python": ">=3.9",
  "keywords": ["apl", "arabic", "mylib"]
}
```

3. حط ملف الكود `mylib_funcs.py` وفيه جداول الكلمات:

```python
import json

MYLIB_FUNCS = {"قراءة": "json.loads"}          # دالة: الكلمة → الدالة
MYLIB_PATTERN = r"(?<!\w)قراءة\s*\("            # الريجيكس اللي بيلاقيها
MYLIB_METHODS = {"تحويل": "dumps"}              # دوال بعد النقطة
MYLIB_METHOD_PATTERN = r"\.تحويل\s*\("
IMPORT_CHECK = r"(?<![\w.])json\."              # إمتى الكود يحتاج الـ import
IMPORT_MODULES = ["json"]
```

4. جرّبها محليًا:

```
عمار مكتبة تحميل ./مجلد-المكتبة
عمار -c 'اطبع قراءة("{\"أ\": 1}")'
```

5. انشرها على GitHub، وأي حد يقدر يثبتها بـ `عمار مكتبة تحميل مالك/ريبو`.

مكتباتنا المنشورة: 116 مكتبة، كل واحدة في ريبو مستقل بالاسم `apl-<الاسم>`، وكل ريبو
فيه الكود والكونفيج وREADME بالكلمات اللي بيضيفها والرخصة. القايمة الكاملة في
[APL-Docs](https://github.com/AmmarBasha2011/APL-Docs).

## الأمثلة

الأمثلة كلها في ريبو عام لوحده: **[APL-Examples](https://github.com/AmmarBasha2011/APL-Examples)**.
كل مثال له رقم واسم وملف وملخص، والريبو فيه `index.json` وREADME فيه الجدول كامل.

```
عمار مثال قائمة             # أول 40 مثال (--الكل للكل)
عمار مثال بحث مصفوفة        # الأمثلة اللي اسمها أو وصفها فيه الكلمة
عمار مثال حمل 1             # تنزيل مثال في المجلد الحالي
عمار مثال جرب calculator    # تنزيله وتشغيله على طول
```

الأوامر دي بتقرأ من ريبو APL-Examples بتاعنا بس، مش من أي ريبو تاني.
