# APL — لغة البرمجة عمار (Ammar Programming Language) **v1.0.0**

**لغة برمجة كاملة بالعربية.** تكتب كود عربي، يتحول تلقائياً إلى بايثون أصلي وينفذ مباشرة.

```apl
المتغير اسم = ادخل("ما اسمك؟ ")
اطبع "أهلا بك يا", اسم
```

---

## تحميل

```powershell
git clone https://github.com/AmmarBasha2011/APL
cd APL
```

## التشغيل

```powershell
.\apl example.apl              # تشغيل ملف
python apl.py example.apl      # أو مباشرة
.\apl_notepad                  # فتح المحرر الرسومي
```

افتح `playground.html` في المتصفح للبرمجة أونلاين دون تنصيب.

## الأوامر الكاملة

### متغير
```
المتغير اسم = "عمار"
المتغير عمر = 25
المتغير x = صحيح(ادخل("رقم: "))
خاص المتغير سر = 123          # ← __سر
عام المتغير ظاهر = "علني"     # ← ظاهر
```

### طباعة وإدخال
```
اطبع "مرحبا"                   اطبع "الاسم:", اسم
اطبع_بدون "نص"                 # بدون سطر جديد ← print(..., end="")
المتغير اسم = ادخل("ما اسمك؟ ")
المتغير عمر = صحيح(ادخل("كم عمرك؟ "))
```

### شرط
```
لو عمر >= 18:
    اطبع "بالغ"
الا لو عمر > 12:
    اطبع "مراهق"
الا:
    اطبع "طفل"
```

### شرط ثلاثي (ternary)
```
المتغير ن = 1 إذا صواب والا 0
المتغير حالة = "كبير" إذا عمر >= 18 والا "صغير"
```

### الحلقات
```
طالما i < 5:
    اطبع i; المتغير i = i + 1

لكل i في نطاق(5):
    اطبع i

لكل اسم في ["عمار", "علي"]:
    اطبع اسم
```

### دوال
```
دالة جمع(أ, ب):
    ارجع أ + ب

اطبع جمع(5, 3)
خاص دالة _مخفي():             # ← def __مخفي()
عام دالة ظاهر():              # ← def ظاهر()
```

### سهم (lambda)
```
المتغير ضعف = سهم س: س * 2
المتغير جمع = سهم س, ص: س + ص
اطبع ضعف(5)                    # 10
```

### صنف / قاعدة (class)
```
صنف شخص:
    دالة __init__(ذات, اسم):
        ذات.اسم = اسم
    دالة سلام(ذات):
        اطبع "مرحبا", ذات.اسم

صنف طالب(شخص):                 # وراثة
    تمرير
```

### Break / Continue / Yield
```
توقف                            # ← break
اكمل                            # ← continue
مولد س                          # ← yield س
```

### Try / Except
```
حاول:
    المتغير x = صحيح(ادخل("رقم: "))
إمسك ValueError:
    اطبع "رقم غير صحيح"
إمسك:
    اطبع "خطأ غير متوقع"
```

### استيراد
```
استورد math
استورد math as m
من math استورد sqrt
```

### مطابقة (match / case)
```
حالة اختيار:
    قيمة 1:
        اطبع "واحد"
    قيمة 2:
        اطبع "اثنان"
    افتراضي:
        اطبع "غير معروف"
```

### مع..مثل (with..as)
```
مع فتح("file.txt") مثل f:
    اطبع اقرأ(f)
```

### JSON
```
المتغير د = جسون('{"اسم": "عمار"}')          # ← json.loads
المتغير ن = جسون_تحويل(د)                     # ← json.dumps
```
> يستورد `json` تلقائياً.

### التاريخ والوقت
```
المتغير الآن = الساعة()          # ← datetime.datetime.now()
المتغير اليوم = التاريخ()        # ← datetime.date.today()
```
> يستورد `datetime` تلقائياً.

### ملفات
```
المتغير f = فتح("file.txt", "w", ترميز="utf-8")
اكتب(f, "نص")
اقرأ(f)
اغلق(f)

احذف ملف "file.txt"             # ← os.remove
انشئ مجلد "جديد"                # ← os.mkdir
نسخ ملف "a.txt" إلى "b.txt"     # ← shutil.copy
نقل ملف "a.txt" إلى "b.txt"     # ← shutil.move
المتغير ح = حجم_ملف("a.txt")    # ← os.path.getsize
المتغير ق = قائمة_ملفات(".")    # ← os.listdir
```

### HTTP طلب
```
المتغير استجابة = طلب("https://example.com")
# ← _apl_fetch("https://example.com")
```
> يستورد `urllib.request` تلقائياً.

### دوال مدمجة إضافية
```
كل([صواب, خطأ])                 # ← all
أي([صواب, خطأ])                 # ← any
خريطة(دالة, قائمة)              # ← map
فلترة(دالة, قائمة)              # ← filter
تجميع(ق1, ق2)                   # ← zip
عشوائي(نطاق(10))                # ← random.choice
نوع(5)                          # ← type
عدد(قائمة)                      # ← enumerate
انتظر(1)                        # ← time.sleep
المتغير ت = وقت()               # ← time.time
تمثيل(5)                        # ← repr
ثنائي(5)                        # ← bin
سداسي(255)                      # ← hex
ترتيب("أ")                      # ← ord
رمز(65)                         # ← chr
من(س, صحيح)                     # ← isinstance(س, int)
اخرج(0)                         # ← exit(0)
تأكد(س > 0)                     # ← assert س > 0
```

### زخارف (decorators)
```
خاصية اسم                       # ← @property
محدد اسم                        # ← @name.setter
محدد_حذف اسم                    # ← @name.deleter
```

## دوال تحويل وأنواع

| عربي | بايثون | عربي | بايثون | عربي | بايثون |
|------|--------|------|--------|------|--------|
| `صحيح(...)` | `int(...)` | `قائمة(...)` | `list(...)` | `نطاق(...)` | `range(...)` |
| `نص(...)` | `str(...)` | `مجموعة(...)` | `tuple(...)` | `طول(...)` | `len(...)` |
| `عشري(...)` | `float(...)` | `مصفوفة(...)` | `set(...)` | | |
| `منطق(...)` | `bool(...)` | `قاموس(...)` | `dict(...)` | | |

## دوال رياضية

| عربي | بايثون | عربي | بايثون |
|------|--------|------|--------|
| `مطلق(-5)` → `abs(-5)` | `قوة(2,3)` → `pow(2,3)` |
| `جذر(16)` → `math.sqrt(16)` | `أكبر(1,2,3)` → `max(1,2,3)` |
| `أصغر(1,2,3)` → `min(1,2,3)` | `مقرب(3.7)` → `round(3.7)` |
| `مجموع([1,2,3])` → `sum([1,2,3])` | `مفرز([3,1,2])` → `sorted([3,1,2])` |
| `ط` → `math.pi` | `ه` → `math.e` |

## دوال السلاسل والقوائم والمجموعات

| عربي | بايثون | عربي | بايثون |
|------|--------|------|--------|
| `.تقسيم(" ")` → `.split(" ")` | `.تقليم()` → `.strip()` |
| `.ضم(["أ","ب"])` → `.join(["أ","ب"])` | `.استبدال("أ","ب")` → `.replace("أ","ب")` |
| `.أضف(5)` → `.append(5)` | `.بداية("أ")` → `.startswith("أ")` |
| `.حذف()` → `.pop()` | `.نهاية("ب")` → `.endswith("ب")` |
| `.عكس()` → `.reverse()` | `.علوي()` → `.upper()` |
| `.فرز()` → `.sort()` | `.سفلي()` → `.lower()` |
| `.نسخ()` → `.copy()` | `.اتحاد(ق)` → `.union(ق)` |
| `.عد(5)` → `.count(5)` | `.تقاطع(ق)` → `.intersection(ق)` |
| `.بحث(5)` → `.index(5)` | `.فرق(ق)` → `.difference(ق)` |
| `.أزل(5)` → `.remove(5)` | |
| `.وسع([1,2])` → `.extend([1,2])` | |
| `.أدخل(0,5)` → `.insert(0,5)` | |


## رسائل الخطأ بالعربية

جميع أخطاء بايثون تُعرض بالعربية تلقائياً:
```
خطأ في الصياغة           خطأ: متغير غير معروف
خطأ في نوع البيانات      خطأ: القسمة على صفر
خطأ: الملف غير موجود     خطأ: المفتاح غير موجود
...و 20+ رسالة خطأ أخرى
```

## مثال كامل — آلة حاسبة

```apl
دالة آلة_حاسبة():
    اطبع "=== الآلة الحاسبة ==="
    اطبع "1- جمع\n2- طرح\n3- ضرب\n4- قسمة\n5- خروج"

    المتغير اختيار = صحيح(ادخل("اختر العملية: "))

    لو اختيار >= 1 و اختيار <= 4:
        المتغير أ = عشري(ادخل("أدخل الرقم الأول: "))
        المتغير ب = عشري(ادخل("أدخل الرقم الثاني: "))

        لو اختيار == 1: اطبع "النتيجة:", أ + ب
        الا لو اختيار == 2: اطبع "النتيجة:", أ - ب
        الا لو اختيار == 3: اطبع "النتيجة:", أ * ب
        الا لو اختيار == 4:
            لو ب != 0: اطبع "النتيجة:", أ / ب
            الا: اطبع "خطأ: القسمة على صفر"
    الا لو اختيار == 5: اطبع "مع السلامة"; ارجع
    الا: اطبع "اختيار غير صحيح"
```
