# APL — لغة عمار البرمجية

لغة برمجة عربية مبنية على Python. الكود بيتكتب بالعربي، وبيتحوّل لـ Python نظيف ويشتغل.
اللغة نفسها مش محتاجة أي مكتبة خارجية، ومبنية على مكتبة Python القياسية بس.

**التوثيق الرسمي الكامل: [APL-Docs](https://github.com/AmmarBasha2011/APL-Docs)**

## التثبيت

اللغة شغالة بـ Python 3.9 أو أحدث، من غير أي حزمة إضافية:

```
git clone https://github.com/AmmarBasha2011/APL.git
cd APL
python apl.py نسخة
```

أو نزّل الملف التنفيذي من تبويب Actions (بناء يدوي، ويندوز ولينكس، بدون ماك).

## أول برنامج

```
اطبع "أهلاً بالعالم"
```

شغّله بـ:

```
عمار شغل hello.apl
```

## أوامر "عمار"

| الأمر | اللي بيعمله |
|---|---|
| `عمار شغل ملف.apl` | تشغيل برنامج |
| `عمار فحص ملف.apl` | فحص الصياغة بدون تشغيل |
| `عمار ترجمة ملف.apl` | طباعة كود Python المترجم |
| `عمار طرفية` أو `عمار` لوحده | موجّه تفاعلي |
| `عمار -c 'كود'` | تنفيذ كود مباشرة |
| `عمار نسخة` | رقم الإصدار |
| `عمار مساعدة` | المساعدة |
| `عمار مسح-الكاش` | حذف الترجمات المخزنة |
| `عمار مكتبة ...` | إدارة المكتبات (تحت) |
| `عمار مثال ...` | إدارة الأمثلة (تحت) |

## ميزات اللغة

- معالجة الأخطاء: `حاول:` / `امسك مثل خطأ:` / `أخيراً:`
- رسائل أخطاء عربية برقم السطر والعمود.
- الأصناف والكائنات: `صنف` / `دالة_إنشاء` / `ذات`، ومعاها الوراثة.
- استيراد ملف APL تاني: `استورد "ملف.apl"`.
- ملفات وإدخال: `اقرأ` / `اكتب` / `ادخل`.
- دوال مختصرة `(س) => س * 2`، فهم القوائم `[ع * 2 لكل ع في قائمة]`، ونصوص منسّقة `"أهلاً {الاسم}"`.
- كلمات التحكم: `لو` / `والا` / `لكل` / `طالما` / `ارجع` / `توقف` / `اكمل` / `قيمة` (match).

## المكتبات

اللغة مابتشحنش أي مكتبة. المكتبات ريبوهات GitHub مستقلة، ومدير الحزم بيجيبها.

```
عمار مكتبة تحميل <اسم>        # من AmmarBasha2011/apl-<اسم>
عمار مكتبة تحميل مالك/ريبو    # من أي ريبو GitHub
عمار مكتبة تحميل <رابط>       # من رابط GitHub كامل
عمار مكتبة قائمة              # المثبتة
عمار مكتبة بحث <كلمة>         # بحث محلي وعلى GitHub
عمار مكتبة حذف <اسم>
```

التثبيت بينزّل الريبو، يقرأ `apl-library.json`، يتأكد إن ملف الكود بيترجم، وينسخه في
`~/.apl/libraries/<الاسم>/`. التثبيت **مابيشغّلش** كود المكتبة؛ الكود بيشتغل وقت
الاستخدام بصلاحياتك، فالمصدر بيظهر في رسالة التثبيت.

### إنشاء مكتبة بنفسك

1. اعمل ريبو GitHub عام، الاسم المقترح `apl-<اسم المكتبة>`.
2. حط فيه ملف `apl-library.json`:

```json
{
  "name": "mylib",
  "version": "1.0.0",
  "title": "مكتبة mylib",
  "description": "كلمات عربية لـ ...",
  "entry": "mylib_funcs.py",
  "requires": [],
  "license": "PSF-2.0",
  "python": ">=3.9",
  "keywords": ["apl", "arabic", "mylib"]
}
```

3. حط ملف الكود `mylib_funcs.py` وفيه جداول الكلمات:

```python
import json

MYLIB_FUNCS = {"قراءة": "json.loads"}          # دالة: الكلمة → الدالة
MYLIB_PATTERN = r"(?<!\w)قراءة\s*\("            # الريجيكس اللي بيلاقيها
MYLIB_METHODS = {"تحويل": "dumps"}              # دوال بعد النقطة
MYLIB_METHOD_PATTERN = r"\.تحويل\s*\("
IMPORT_CHECK = r"(?<![\w.])json\."              # إمتى الكود يحتاج الـ import
IMPORT_MODULES = ["json"]
```

4. جرّبها محليًا:

```
عمار مكتبة تحميل ./مجلد-المكتبة
عمار -c 'اطبع قراءة("{\"أ\": 1}")'
```

5. انشرها على GitHub، وأي حد يقدر يثبتها بـ `عمار مكتبة تحميل مالك/ريبو`.

مكتباتنا المنشورة: 106 مكتبة، كل واحدة في ريبو مستقل بالاسم `apl-<الاسم>`، وكل ريبو
فيه الكود والكونفيج وREADME بالكلمات اللي بيضيفها والرخصة. القايمة الكاملة في
[APL-Docs](https://github.com/AmmarBasha2011/APL-Docs).
